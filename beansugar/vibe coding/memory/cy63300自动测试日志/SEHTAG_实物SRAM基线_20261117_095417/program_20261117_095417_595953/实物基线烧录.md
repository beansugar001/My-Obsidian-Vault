# CY63300 专用 SRAM 基线烧录

实物为 CJPCBT021-G 样品，OpenOCD 配置为 100 kHz JTAG，识别到 TAP `riscv.cpu / 0x1E200A6F`。烧录前独立读取启动扇区 `0x00000000–0x0000FFFF`，与 V160 备份逐字节一致。读取范围以外的 Flash 和 NVR 未纳入本次擦写。

已依次擦除启动扇区内六个非空的 512 字节页。逐页检查读回后，从 `0x00000000` 写入 136 字节镜像。镜像 SHA256 为 `EFD4837FE3CE916690714E976254B740F37B2460A2F1531F4460ABCF9E5F4DCC`。OpenOCD 校验通过，Flash 控制器已退出编程模式，随后独立读取完整 64 KiB，与镜像加擦除态的预期内容逐字节一致，扇区 SHA256 为 `A5605F98BF115C70F49E2245079E0C5271CD0D91CE5ACA4B78C441AC9ADEC938`。

程序启动后应将 `0x13579BDF` 和 `0x2468ACE0` 先后写入 `0x2000F014`，每次由 CPU 读回并保存至邮箱。完成时邮箱标识为 `0x53454231`，完成码为 `0x5345600D`。启动及邮箱结果单独记录。该镜像只验证普通 SRAM 读写。
