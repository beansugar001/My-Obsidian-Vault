# CY63300 寄存器指令对照

上轮实物在 running 和 halted 各有八次整块邮箱读回，异常状态字均为 `0x5741601A`。原程序同地址序列应产生 `0x5741600D`，相差一个立即数 13。对照镜像保留原 `0x94` 的 LUI、`0x98` 的原地 ADDI 和 `0x9C` 的 NOP。前置条件分支改为比较同一寄存器，让预期路径不依赖 SRAM 加载。观测到相同结果时可继续追查，未必对应相同硬件原因。

## 预期邮箱

邮箱基址为 `0x2000F000`。程序只向邮箱写入，未执行 SRAM 加载、外设访问或 CSR 指令。

| 偏移 | 预期值 | 含义 |
| --- | --- | --- |
| `0x00`、`0x08`、`0x0C` | `0x57416000` | 固定底值和目标寄存器独立时的源值 |
| `0x04` | `0x5741600D` | 源和目标不同，ADD 13 |
| `0x10` | `0x5741601D` | 原地加 29，源值在较早指令中产生 |
| `0x14` | `0x11111000` | 两个固定寄存器不相等，BEQ 应不取 |
| `0x18` | `0x22222000` | 两个固定寄存器不相等，BNE 应取 |
| `0x1C` | `0x5741600D` | 原地址相邻 LUI 和原地 ADDI |
| `0x20` | `0x2D5A7000` | 固定读回校验图样 |
| `0x24` | `0x53457000` | 完成标记，由单条 LUI 构造 |

Icarus Verilog 在公开 CPU RTL 上通过原样测试。另在仿真中把 `0x9C` 的 NOP 替换为相同 ADDI，使 `0x1C` 读回恰好变成 `0x5741601A`，其余字段保持正常。该对照只验证重复加法的数值特征。

镜像长度 196 字节，SHA256 为 `BDBBC404E911A7BF7FE44467D734AE79D76A068E0CA088081141F795374DBF2E`。

## 实物判别

启动扇区的历史独立读回 SHA256 为 `B7B81AB8C5D55E18ABDB8139F5BF8800E55DC61DBF36FFFC6E7D038620496DAD`。实物阶段先核对当前扇区与此备份逐字节一致，再只擦写首个 512 字节页。完整扇区校验后冷启动，整块和单字读取邮箱。若只有相邻指令组复现 `+26`，优先查这组指令时序。若固定图样或两种读取方式不一致，先查写入与回读链路。若纯寄存器分支失败，可将问题范围缩小到无需 SRAM 加载的执行路径。

本轮只有离线编译和仿真。实物仍保留上一轮暂停状态。
