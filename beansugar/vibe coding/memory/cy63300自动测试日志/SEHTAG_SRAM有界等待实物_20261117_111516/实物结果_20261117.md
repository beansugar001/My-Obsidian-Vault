# CY63300 SRAM 有界等待实物结果

只擦写首个 512 字节启动页，写入 312 字节测试镜像。写后独立读回 64 KiB，SHA256 为 `F17BF7BC07D860DD25957E9141B2CB38BDB6EB577322D3D4543477B8A134B65F`。冷启动后再次读回 312 字节，与烧录镜像逐字节一致。CPU 为 running。采样阶段只读，未暂停 CPU 或写入测试字。

| 项目 | 参考仿真 | 实物 |
| --- | --- | --- |
| 固定不匹配组 | 32 次，最后读 `0x13579000`，上限退出 | 8 次整块和 8 轮逐字读回均一致，符合预期 |
| 第 7 次后改成匹配值 | 第 8 次读到 `0x53454000` 并匹配退出 | 匹配值及退出码正确，次数异常且持续增加 |
| 完成标记 | `0x4C576000` | 全部采样正确 |

变值组次数地址 `0x2000F010`。按“整块、逐字”交替采样的实际顺序，依次读到 `0x2E, 0x6B, 0xC9, 0x105, 0x164, 0x196, 0x1EB, 0x222, 0x280, 0x2B6, 0x30F, 0x34B, 0x3A6, 0x3E2, 0x439, 0x46F`，即 46 至 1135，全部严格递增。其余字段一致。两种读取都经过同一 JTAG 调试链路，尚无法独立排除该链路的动态读回异常。

反汇编中 `0x128` 将计数 s5 写入当前结果区，`0x134` 返回调用方。第二组返回后，`0x60` 写完完成标记，`0x64` 进入自跳转。正常仿真完成后不会再写迭代字段。实物结果表明首次异常在变值组的计数或执行过程，现有采样不足以区分软件执行流持续更新该字段与调试回读异常。

下一步在本次镜像和供电条件下，一次 Halt 前后紧邻采样同一计数字和整块邮箱，确认计数是否随 CPU 停止。暂停后仍变化时优先查读回链路。若暂停后冻结，再检查第二组返回及终止路径，区分循环重复执行和计数异常。
