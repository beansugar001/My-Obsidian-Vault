# OpenOCD 初始化阶段对照

- 上电、尚未连接 OpenOCD 时，H2-4 约 3.3 V。初始化结束后用户仍测得约 3.3 V。
- 目标扫描链 IDCODE 为 0x1E200A6F，日志显示 hart 正在运行。
- 已执行 poll off，但旧版 OpenOCD 在 Tcl 循环调用 sleep 100 busy 时仍通过命令回调轮询 hart。在 STEP_INIT_COMPLETE 至 STEP_SESSION_END 之间记录到 488 次后台 DMSTATUS 读取请求。人工门控的单笔 DMSTATUS 和 SRAM 读均未发出。
- 停止会话并保留日志。本次的高电平证据对应初始化和本版等待循环的后台轮询，未取得干净的初始化对照，也未测试单笔 SRAM。未主动发目标写入、halt、复位或烧录命令。
- 修订稿用 Jim Tcl 的 after 100 和 puts 等待与标记，同一个 OpenOCD 可执行文件在无目标配置的离线测试中确认 after 可用。下一次连板须检查初始化后等待区间实际没有 DMI 扫描，再逐项继续。
