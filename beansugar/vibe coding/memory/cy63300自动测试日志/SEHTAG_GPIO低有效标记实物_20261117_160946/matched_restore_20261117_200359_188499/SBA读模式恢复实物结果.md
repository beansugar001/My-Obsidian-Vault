# SBA 读模式恢复对照实物结果

独立冷启动后 H2-4 约 3.3 V。一次 SRAM 字读取 0x2000F010 返回 8。SBCS 原始读数依次为读前 0x20040404、读后 0x00150000、恢复后 0x00040000。可写读模式字段掩码 0x001F8000 下，恢复值与读前相同。三次读数均通过 busy/error 检查。日志记录了一次显式 SBCS 恢复写入 0x00040000。全寄存器读数其余位与初始值不同，本轮结论只覆盖读模式字段。

恢复后至发出 shutdown 的等待阶段无 DMI 扫描。恢复写前有一次 OpenOCD 内部 DMSTATUS 读取。退出阶段有后台 DMSTATUS 读取、resumereq 和清除 dmactive。用户确认会话仍开着时 H2-4 约 3.3 V，退出后测得低电平。OpenOCD 返回码为 0。

把 SBA 读模式恢复到读前设置后仍可复现退出后低电平。当前证据无法区分保留的 SBA 地址、其他访问状态和退出动作各自的影响。
