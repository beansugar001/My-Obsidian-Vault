# 冷启动后单读 SRAM 与退出分开观测

冷启动后 H2-4 约 3.3 V。万用表黑笔接 H2-2/GND，红笔接 H2-4。OpenOCD 初始化后单读 SRAM 地址 0x2000F010，读回 8。等待至少 10 秒后让观察者测量。用户确认 OpenOCD 会话仍打开时 H2-4 约 3.3 V，明确退出后再测为低电平。

原始跟踪记录单字读取 10 次 DMI 扫描，读完到调用 shutdown 之间 0 次。退出阶段共 6 次扫描，包含一次后台 DMSTATUS 读取、DMCONTROL=0x40000005（resumereq）及 DMCONTROL=0x00000000（清除 dmactive）。本轮没有单独发起 DMSTATUS 读取。

在本轮条件下，独立 DMSTATUS 读取并非发现退出前高、退出后低的前置条件。退出时的三项调试操作仍在同一观察区间，现有实测不能确定其中哪项触发。此前单读后立即退出曾测得高电平，各轮上电和会话时序有差异。首次未同步的低电平记录没有用于判定阶段。
