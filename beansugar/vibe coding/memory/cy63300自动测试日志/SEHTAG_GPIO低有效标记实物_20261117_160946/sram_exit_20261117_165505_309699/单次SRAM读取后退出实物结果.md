# 单次 SRAM 读取后退出实物结果

OpenOCD 初始化成功，hart 为 running。显式读取 SRAM 字地址 0x2000F010 一次，返回 0x00000008，随即退出，返回码为 0。会话结束后，用户实测 H2-4 仍约 3.3 V，黑表笔参考 H2-2/GND。本轮沿用了当时的上电状态，日志级别没有记录 DMI 逐笔跟踪。

此前只初始化后退出，H2-4 仍高。此前分步读 DMSTATUS 和相同 SRAM 字后退出，H2-4 拉低。各轮的调试会话历史和等待时间有差异。后续可在同样的冷启动和等待条件下对照，每轮只改变是否单独读取 DMSTATUS，并保留 DMI 跟踪。
