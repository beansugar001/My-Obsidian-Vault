# SBADDRESS0 三点取样实物结果

冷启动后 H2-3 约 0 V、H2-4 约 3.3 V。万用表黑笔接 H2-2/GND。进入本轮后，用户分别确认 OpenOCD 会话仍打开时 H2-4 约 3.3 V，退出后测得低电平。

| 取样点 | SBCS 原始读数 | SBADDRESS0 原始读数 |
| --- | --- | --- |
| 单读前 | 0x20040404 | 0x00000000 |
| 单读后 | 0x00150000 | 0x00000000 |
| 恢复读模式后 | 0x00040000 | 0x00000000 |

日志记录 OpenOCD 为单字读取向 SBADDRESS0 写入 0x2000F010，SRAM 数据读回 8。三笔显式 SBADDRESS0 读取的 DMI 响应均为 0。这个结果只确定通过当前 DMI 路径读到的值，内部地址锁存状态未获独立验证。恢复阶段只恢复 SBCS 的可写读模式字段。

结束采样至退出前 0 次 DMI 扫描。退出阶段 6 次 DMI 扫描，包含后台 DMSTATUS 读取、resumereq 和清除 dmactive。OpenOCD 返回码为 0。现有证据尚未确认可见的地址变化，建议先核对 Debug Module 参考实现或厂商资料中 SBADDRESS0 的读回路径，再决定是否开展地址状态对照。
