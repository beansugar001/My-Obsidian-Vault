# CY63300 分步只读与退出对照

同一 496 字节观测镜像。沿用上轮供电，在前一 OpenOCD 会话结束后实测 H2-4 约 3.3 V，再启动本轮。万用表黑笔接 H2-2/GND，红笔接 H2-4。OLED 与 STM32 保持断开。

| 阶段 | 实际动作 | H2-4 电压 |
| --- | --- | --- |
| 初始化 | 唯一 TAP IDCODE 0x1E200A6F，hart 初始 running | 约 3.3 V |
| 单独读取 DMSTATUS | 读请求加响应扫描，共 2 次 DMI 扫描，返回 0x00430C82 | 约 3.3 V |
| 单字读取 SRAM | 0x2000F010 读回 0x00000008，共 10 次 DMI 扫描，包含 SBA 控制及地址设置 | 约 3.3 V |
| 退出会话 | 后台 DMSTATUS 读取和 OpenOCD 退出清理，共 6 次 DMI 扫描 | 低电平 |

三段等待区间记录到 0 次 DMI 扫描，修订的 Tcl 等待生效。发出 shutdown 后，OpenOCD 自动读取 DMSTATUS，再写 DMCONTROL=0x40000005（resumereq，同时保留 dmactive）及 DMCONTROL=0x00000000（清除 dmactive）。脚本未显式发 halt、resume、复位、目标 SRAM/Flash/MMIO 写入。

本轮将 H2-4 拉低的时间区间缩小到最后一次读完后的无扫描等待之后至会话退出。用户报告退出后是低电平，未提供精确下降时刻或低电压数。该证据支持本轮触发与退出路径有关，尚不能区分这三笔 DMI 请求的影响，也尚不能判断先前 SRAM 访问是不是退出触发的前置条件。先前不同采样流程曾在主动退出前读到 DIR=0x3，因此无需把所有历史触发归为退出。

优先做新的冷启动对照，仅初始化后退出，不发单读 SRAM 或额外 DMSTATUS。确认标记是否仍在退出后拉低。该步骤无需改固件。
