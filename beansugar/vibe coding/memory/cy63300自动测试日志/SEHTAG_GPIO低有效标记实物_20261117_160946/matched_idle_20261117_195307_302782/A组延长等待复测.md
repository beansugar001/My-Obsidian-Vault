# A 组延长等待复测

用户在 B 组退出后测得 H2-4 低电平，随后拔插目标板 Type-C 和 DAPLink USB。复测启动前 H2-4 恢复到约 3.3 V。万用表黑笔接 H2-2/GND，红笔接 H2-4。

A 组复测只初始化和等待。会话仍打开时、正常退出后，H2-4 均为约 3.3 V。原预留 SRAM 访问时点至退出间隔 116.362 秒，包含等待用户报读数的时间。此间隔长于 B 组的 69.369 秒。日志确认初始化后至退出前 0 次 DMI 扫描、退出阶段 6 次 DMI 扫描。OpenOCD 返回码为 0。

延长等待后 A 组仍保持高，支持下一步优先分析 SRAM 读取留下的 SBA 状态与 OpenOCD 退出的交互。两组的实际等待时长不同，具体触发操作尚待区分。
