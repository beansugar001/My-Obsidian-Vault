## 当前实物断点

当前板上的最后一次烧录是 GPIO 低有效标记镜像，496 字节。最近一次实物对照是 matched_address_20261117_202228_483266。冷启动时 H2-3 约 0 V、H2-4 约 3.3 V。单读 0x2000F010 返回 8。SBCS 依次读回 0x20040404、0x00150000、0x00040000，可写模式字段已恢复。SBADDRESS0 三次读回均为 0，DMI 日志仍记录了 OpenOCD 写入地址 0x2000F010。H2-4 在会话仍打开时约 3.3 V，退出后测得低电平。该低电平是最后一次已确认读数，当前瞬时电压未重新测量。

只初始化并退出的 A 组两次退出后均约 3.3 V，其中延长等待的复测为 116.362 秒。加单次 SRAM 读取的 B 组退出前约 3.3 V、退出后低，等待 69.369 秒。读完立即退出的旧对照曾保持高，各轮启动历史及等待条件有差异。

## 固件复查

在 offline_audit_20261117_202846_9750 中用原构建脚本重编译。新 496 字节与烧录输入、归档 64 KiB 独立读回的前 496 字节逐字节相同。镜像 SHA256 为 A678367796DFC2DD3336158FCC9E97029FC84634C1C8739315C05B44F2F9DD79。

反汇编显示 0x1D8 为跳回自身。正常路径先写完成字 0x52547000，设置 s11=1 并拉低 H2-3，再进入该循环。mark_record 检查 s11，非零时通过 GPIOC_DIR 的 bit 1 拉低 H2-4。普通路径仿真通过，H2-3 低、H2-4 高。仿真刻意在终止地址注入一次回跳的对照也通过，H2-4 变低。

测试台使用 TinyRISC-V 参考核和 GPIO 寄存器模型，调试 halt/reset 等输入固定为零。它验证了正常控制流和标记逻辑，无实物 OpenOCD 退出过程。实物 H2-4 拉低说明标记所对应的电平发生了变化，缺少同步 PC 或 GPIO 写入来源记录，无法据此单独确认 CPU 重新执行了整段 SRAM 写回。

## 主机时序复查

最近一轮结束采样至下发退出约 75.168 秒，跟踪记录 0 次 DMI 扫描。退出处理记录 6 次扫描，涉及三笔 DMI 请求，依次为读 DMSTATUS、写 DMCONTROL 的 resumereq、清除 dmactive。恢复 SBCS 前还记录到了一次 OpenOCD 内部轮询，说明脚本命令边界也可能带来隐式访问。万用表把下降夹在两次测量之间，无法逐条区分退出的三个动作。

## SBADDRESS0 读回线索

本地参考 RTL D:/project/tools/tinyriscv-master/rtl/debug/jtag_dm.v 的 DMI 读选择在第 162–199 行，没有 SBADDRESS0 分支，默认返回 0。写选择的第 272–276 行会锁存 SBADDRESS0，在配置允许时更新总线地址。该参考实现说明零读回可以与成功访问 SRAM 同时出现。真实流片版本的读回实现和内部地址状态仍待厂商 RTL 或其他独立观测确认。

## 恢复测试的入口

本轮只做离线复查和进度记录。恢复时先从冷启动复核 H2-3 约 0 V、H2-4 约 3.3 V，再继续区分退出阶段各动作。优先核对实际 OpenOCD 版本的退出路径和可取得的芯片调试资料。若实物继续测试，保持现有固件，采用能独立区分退出操作和同步记录标记的对照。后续判断保留两个证据边界，即 SBADDRESS0 的 DMI 读回与内部锁存值，以及 H2-4 电平与 CPU 实际执行路径。
