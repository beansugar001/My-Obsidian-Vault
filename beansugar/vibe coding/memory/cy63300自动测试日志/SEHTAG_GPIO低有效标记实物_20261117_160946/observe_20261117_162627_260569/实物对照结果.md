# CY63300 DAPLink 接入及只读对照

同一 496 字节低有效观测镜像，OLED 和 STM32 始终断开。万用表黑表笔为 H2-2/GND，红表笔在只读窗口固定 H2-4。

| 条件 | H2-3 | H2-4 |
| --- | --- | --- |
| 仅 Type-C 冷启动 | 符合约 0 V 的预期 | 符合约 3.3 V 的预期 |
| 接回 DAPLink 并冷启动，尚未发命令 | 约 0 V | 约 3.3 V |
| OpenOCD 只读对照 | 未同步测量 | 从约 3.3 V 降为低电平，并保持低 |

OpenOCD 完成 5 秒静默、约 10 秒采样、5 秒静默。活跃段执行 334 次 SRAM 字读取，用时 10020 ms。初始、活跃前、活跃后、结束四次快照的 GPIOC_ODR、GPIOC_DIR 均为 0x0、0x3，DIR 在第一组快照中已经为 0x3。首个计数、第二个计数及第二个副本均为 8，完成字均为 0x52547000。本阶段未发目标写入、halt 或复位命令。

实物低电平支持完成之后触发了 GPIO 重复写回标记，即便读到的计数值未变。首个 DIR 读数已为 0x3，因此不能将触发定位到活跃段，也尚不能区分 OpenOCD 初始化与最早的几笔只读请求。用户没有报告确切下降时刻和最低电压。

下一轮需要重新上电清除锁存状态。先观察只做 OpenOCD 初始化并保持连接、关闭后台轮询的阶段。若 H2-4 仍高，在同一会话中单独读取 DMI 状态。若仍高，再发单笔 SRAM 读取。每步等用户确认电压后再继续，H2-4 第一次拉低时停止增加访问。
