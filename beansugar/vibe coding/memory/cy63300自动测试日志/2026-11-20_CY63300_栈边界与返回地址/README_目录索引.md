## 一分钟结论

- 样片 3/3（round2_srst_*）：整段栈边界**未成立**——开安全检查后一笔未登记栈写既不提交（frame+8 保持注毒 0xBBBBBBBB）也不报异常（mcause=0、陷阱标记未写），CPU 停摆。
- 返回地址：`sw ra,28(sp)` 落地为 0x000000E0（=0xe0 返回点），CPU 自检一致（r0=1），但**无金丝雀、无影子栈**。
- 局部缓冲区长度检查：count 2→复制、3→拒并保持、0x40000001→拒并保持，样片 3/3 通过。
- 复位能力：只有 `reset_config srst_only srst_nogate` + `reset run` 能真正重启（命令本身报 FAIL、TAP 掉线，属预期）；烧写**不会**触发重启；`reg pc 0x0` 与默认 ndmreset 都无效；单步不可用。

## 判据（与总交接一致）

- 通过：返回码符合且**可靠快照**逐字一致；
- 未通过：可靠证据表明目标内容确实变化，或返回码不符；
- 待确认：CPU 自检与 JTAG 冲突、前后值无法对应同一轮。
