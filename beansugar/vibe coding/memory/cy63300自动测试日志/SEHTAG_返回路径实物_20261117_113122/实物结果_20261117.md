# CY63300 直接跳转与 JALR 返回对照实物结果

仅擦写首个 512 字节启动页并写入 372 字节对照镜像。随后独立读回完整 64 KiB，SHA256 为 `683D057D8AB5A875E1D532DB8C0371D0368182BC7E71925992CB2143AC285485`。冷启动后只读回查 372 字节，实际内容与烧录文件逐字节一致。

| 项目 | 直接跳转组 | JALR 间接返回组 |
| --- | --- | --- |
| 计数预期 | 8 | 8 |
| 计数实物 | 16 次读取均为 8 | 交替读取时从 42 增至 1086 |
| 最后读值与退出码 | `0x53454000 / 0x4D415000` | `0x53454000 / 0x4D415000` |
| 返回前后标记 | `0x52545000 / 0x52546000` | `0x52545000 / 0x52546000` |
| 判定 | 通过 | 计数异常 |

共用完成标记 `0x52547000` 在八次整块、八轮逐字读取中始终有效。两种读取均经同一 JTAG 链路。间接返回组计数按采样顺序为 42、90、183、237、333、391、496、553、651、708、799、848、925、969、1044、1086。其余邮箱字段稳定。本轮冷启动后仅执行只读采样。

当前证据将异常范围缩小到第二组及其返回路径。直接组和间接组除返回形式外，还分别处于第一、第二组，并写入不同邮箱地址，因此不能确定 `JALR` 指令本身故障。返回后与完成标记已经出现，单纯“从未返回”也无法解释这批读数。

下一步保持两组顺序、代码位置、测试参数及邮箱地址，只把 `0x170` 的间接返回换成通往同一返回点的直接跳转。复测第二组。若稳定为 8，继续核对间接目标计算或链接寄存器。若仍增长，固定地址读回、组顺序及返回后的执行仍需检查。本轮未测试 SEHTAG 保护功能。
