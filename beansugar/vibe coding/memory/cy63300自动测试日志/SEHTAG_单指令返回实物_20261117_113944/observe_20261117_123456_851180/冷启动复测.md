# 单指令返回对照的确认冷启动复测

用户确认按指定流程断电后重新上电，并接回 DAPLink。只读会话确认 CPU 为 running，实物启动代码前 372 字节与将 `0x170` 改为直接 JAL 的镜像逐字节一致。未再次擦写或改变目标状态。

| 字段 | 本轮读回 |
| --- | --- |
| 第一组计数 | 16 次均为 8 |
| 第二组计数 | 42、98、203、260、351、406、515、571、663、722、811、872、970、1019、1121、1176 |
| 两组匹配值和退出码 | 均为 `0x53454000 / 0x4D415000` |
| 返回前、返回后和完成标记 | 均稳定且符合预期 |

完成后的第二组计数再次增长。此前 47 至 1176 的会话没有用户单独确认的冷启动记录，本轮补足了这一条件。下一项是在同一次 CPU 写回中，把同一个计数存到两个独立 SRAM 字，比较原地址与副本。
