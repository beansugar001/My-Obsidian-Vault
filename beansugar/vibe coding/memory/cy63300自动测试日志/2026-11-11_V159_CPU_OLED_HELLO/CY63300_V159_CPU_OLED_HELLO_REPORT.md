## 待批准的非易失操作与验收

比较实物备份与 V159 候选发现 683 个字节包含 0→1 位变化，需要先擦除。项目工作规则要求明确确认 Flash 写入与擦除。本次请求的最大擦除范围为主 Flash sector 0（0x00000000–0x0000FFFF），只编程候选范围 0x00000000–0x00000847。历史 V118 第一次擦除触发只观察到 0x00000000–0x000001FF 变为全 FF，因此按实物读回核对擦除结果，擦除未覆盖候选区域时先停下来判定。sector 1 与 NVR 不在范围内。擦写中断可能使入口固件不可启动，现有备份可供另行恢复。

1. 复核 DAPLink、Flash 读模式、快照及镜像 SHA256，再进行已批准范围的擦除与编程。全量读回对比候选镜像及尾部，确认退出编程模式。
2. STM32 保持高阻并准备抓包，用户对 CY63300 上电，由芯片自然启动。既往 resume 0 返回 PC=0x64，V159 不依赖写 DPC、resume 0 或猜测入口。
3. 抓包对比 6 帧地址与载荷，核对 123 ACK 和 6 次 STOP，观察屏幕。最后检查邮箱：magic 0x4D423159、result=0、FIFO 写入数 117、STOP 数 6、完成标志 0x1590600D。若屏幕原先显示 Hello，须以新一轮抓包和邮箱作为本次启动的证据。
