# SEHTAG 写提交等待逻辑仿真

日期 2026-11-16。使用 Icarus Verilog 12.0。checked_commit.v 是独立仿真参考模块，未接入 Repo_Fanglongrui 原版 CPU 或 RIB。未操作实物。

## 六项断言通过

| 条件 | 观察结果 |
|---|---|
| 同一请求等待判定 5 拍 | 0 次提交，存储原值保持 |
| 收到编号不同的判定 | 0 次提交 |
| 收到编号匹配的允许判定 | 只提交 1 次，存储更新 |
| 收到编号匹配的拒绝判定 | 1 次拒绝，0 次写提交 |
| 允许后下游连续 3 拍未就绪 | 保持待写数据，下游就绪后只提交 1 次 |
| 待判定期间发生复位 | 撤销待处理请求，随后的旧判定不触发写入 |

## 接入条件

参考逻辑仅允许一笔在途请求，检查接口在已接收请求后提供带编号的判定。接口上游需要管理编号和复位，避免仍可能返回的旧判定与新请求重用同一编号。当前不接受与新请求同拍返回的判定。拒绝脉冲尚未映射到 CPU 异常路径。未验证公开仓库默认的 CPU、BnBCache 与 RIB 提交时序。

后续把参考逻辑的验收断言应用到独立 CPU 副本，核对停顿、恢复与合法写入次数。验证公开版本和样片行为需要额外依据。

复现入口 run.ps1。run.log 和 commit.vcd 为原始结果。
