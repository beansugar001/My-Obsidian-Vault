# CY63300 V147 绿色载板 SCL 电压与 GPIO 输入对照

沿用 V146 线束与同一 STM32 SRAM 拉低程序。黑表笔接蓝板 H2-2/GND。用户复核本轮红表笔实际接在 **绿色载板上与 H4-8/SCL 对应的焊点**。早先按蓝板 H4-8 记录的测点已更正。该信号在 CJPCBT021-G 绑定资料中标为 COB 11 号焊盘、PAD8。CY63300 的 PERI_CLKEN=1、PERI_RST=0、GPIOB DIR=0、AFR1=0、PUPD=0x300。此阶段 CY63300 目标 MMIO 写入为 0，硬件 I²C 保持关闭。

- STM32 先空闲 14 秒，再只开漏拉低 SCL 15 秒，最后释放。SCL 低期间 STM32 的 PB8/PB9 输入两次均为 0x200，结束 GPIOB_CRH=0x44444444，两脚回到高阻。
- 11:02:41–11:02:56 拉低窗口内，用户在上述绿色载板焊点测到 **0.078 V**。本轮未另报空闲实测电压。
- CY63300 同一低电平窗口的 69 个稳定采样全部为 GPIOB_IDR=0x2C，GPIOB2/SCL 仍读高。空闲和释放阶段也均为 0x2C，CY63300 共取样 163 次。

V146 在蓝板 H2-3 观察到低电平，V147 在绿色载板焊点确认低到 0.078 V，证明本次拉低已到达绿色载板该测点。优先调查从该焊点到裸片 PAD8 的走线和绑定，以及 PAD8 到 GPIOB2 的输入路径。绿色板焊点的低电平无法直接确认点胶下裸片焊点的电压，现有证据不能单独认定芯片或绑定损坏。下一项可用相同方法测绿色载板的 SDA/PAD9 焊点，并对照 GPIOB_IDR[3]，区分 SCL 单线异常和两线共同异常。
