# CY63300 V141 GPIO 开漏 OLED 双地址探测

## 实物结果

用户重新上电。JTAG 使用已知探针和 100 kHz 配置，CPU Halt 一次，PERI_CLKEN/PERI_RST 各三次读回 0。开启 GPIO 时钟，核对 GPIOB AF0、输入、低锁存，设置内部上拉及开漏。首次 GPIO IDR=0x20。每笔写前读取另一个安全地址，目标写后独立读回。

| 7 位地址 | 写地址字节 | 第九拍 DIR | 三次 IDR | 观察 | STOP 后 |
|---|---|---|---|---|---|
| 0x3C | 0x78 | 0 | 0x2C、0x2C、0x2C | SCL 高，SDA 高，未观察到 ACK | DIR=0，IDR=0x2C |
| 0x3D | 0x7A | 0 | 0x2C、0x2C、0x2C | SCL 高，SDA 高，未观察到 ACK | DIR=0，IDR=0x2C |

两帧均走完 GPIO START 请求、8 位、输入应答采样与 STOP 请求。保留的寄存器轨迹分别重建出 01111000、01111010。结果 BOTH_ADDRESS_NACK，目标写 57 次，其中 3 次配置、54 次 GPIOB DIR。无异常释放操作、无重复帧。PERI_CLKEN 最后仍为 1，硬件 I²C 时钟全程关闭，FIFO 写入 0 次。无 OLED 命令或显示数据。

## 证据范围与下一步

这是在芯片 GPIO 数字输入上的观测。通过 JTAG/SBA 逐笔驱动，两个地址各自的相邻数据位高电平采样间隔约 0.81–1.17 秒。该实验尚未建立正常速率下同一接线的 ACK 正对照，也未验证 OLED 插座端的实际幅值、边沿、地址解码。两次 NACK 不能单独定位模块、板级线路、输入路由或位模拟时序。

优先在 OLED 接头一侧抓 START 到第九拍，核对 SCL、实际地址位及 SDA 释放。若仪器仍不便接，使用已经验证能驱动该 OLED 的主机，以同一线束正常速率探测 0x3C 和 0x3D，先确认应答地址和线束通路。两者都会比继续增加慢速重发更有区分度。

- 实物结果完成标记出现，OpenOCD 退出码 0，两个地址各有三条 DIR=0、IDR=0x2C 的应答采样记录。
