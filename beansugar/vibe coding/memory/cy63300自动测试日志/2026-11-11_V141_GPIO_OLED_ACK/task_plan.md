# V141 OLED 地址应答

- [x] 核对 V135 GPIO 输入语义、V140 现场与用户重新上电
- [x] 离线验证两地址和错误释放分支
- [x] 实测并归档

使用 100 kHz JTAG。冷启动核对 CLKEN/RST=0，最多一次 Halt。只开启 GPIO 时钟；确认 PB2/PB3 GPIO AF0、输入态、低锁存，设置内部上拉、开漏。先后请求 0x3C 和 0x3D 的写地址，每地址最多一帧。每笔目标写前读不同安全寄存器，写后独立读回。第九拍两线输入，采三次；随后生成 STOP 并检查回到输入高电平。若中途失败，最多一次只释放 PB2/PB3，不重发帧。目标写仅限 CLKEN=1、GPIOB PUPD=0x300、OSOD=0xC 和 DIR=0/4/8/12。无硬件 I²C/FIFO 写入、复位、resume 或非易失修改。

- V141 实测两帧已完成，目标写入 57 次，ACK 采样均为 SDA 高。合并日志、命令、离线回归和 marker 随报告归档。
