# CY63300 低有效 GPIO 标记

静态校准在拔除 DAPLink 时实测 H2-3 为 0 V、H2-4 为 3.3 V。新镜像沿用开漏拉低方式，初始化完成后先释放两脚，由内部上拉维持高电平。计数测试完成时把 H2-3 锁存为低。完成后若 CPU 再次进入写回记录路径，把 H2-4 也锁存为低。

## 离线结果

- Icarus Verilog 使用 TinyRISC-V 参考核与 GPIO 寄存器模型。正常路径观察到两脚先释放，最后 H2-3 低、H2-4 高，计数为 8。
- 仿真在终止位置注入跳转以验证观测标记。再次进入写回路径后 H2-4 拉低。注入只在测试台内，固件终止指令为原地等待。
- 新旧镜像的原计数、写回、分支和返回指令区间 0x000–0x087、0x0F0–0x173 逐字节相同。
- 新镜像 496 字节，范围 0x00000000–0x000001EF，SHA256 为 A678367796DFC2DD3336158FCC9E97029FC84634C1C8739315C05B44F2F9DD79。
- 烧录入口的离线审计通过。目标板仍运行 136 字节静态校准镜像。本阶段未连接硬件或变更 Flash。

## 实物对照

1. 授权后核对当前 64 KiB 读回与校准备份一致，仅擦除首个 512 字节启动页，写入新镜像并独立读回校验完整 64 KiB。任一校验失败停止。
2. 烧录结束后先断电并在断电时拔除 DAPLink 板端插头，再仅用 Type-C 给 CY63300 上电。OLED 和 STM32 保持断开。万用表黑笔固定 H2-2/GND，红笔依次测 H2-3、H2-4。预期为低、高。
3. 再做一轮冷启动对照。断电时接回 DAPLink 板端插头，先给目标板上电，再插 DAPLink USB。先不发 JTAG 命令并记录两脚电压，然后保持板子通电，将红笔留在 H2-4，再做有界只读窗口并复测。每种条件单独记录。
4. H2-3 持续为高时，根据该标记无法确认程序完成，应先检查镜像启动和电平。H2-4 在只读窗口期间降为低且保持低，支持程序在该轮触发了重复写回标记。H2-4 始终为高时，即使调试读值变化，也只能说未观察到该写回路径重入。GPIO 模型结果不能替代实物读数。
