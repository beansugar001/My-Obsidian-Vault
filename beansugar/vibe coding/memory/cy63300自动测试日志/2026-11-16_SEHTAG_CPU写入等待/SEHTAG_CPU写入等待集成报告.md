# SEHTAG CPU 写入等待集成验证

基线为 Repo_Fanglongrui 提交 189fff578a44b61a328af08e32e60ac890b19a91。Icarus Verilog 12.0。使用独立 CPU 适配副本和仓库 RAM 模块，未修改 GitHub 仓库或操作实物。

## 本轮结果

固件从复位入口运行，启用保护，合法分配 32 字节对象，执行一次对象内字写和一次读取。测试台使用 BnBCache 对当前请求给出的判定。仿真适配层将判定传递延后，并将下游就绪再延后。

- 等待判定 3 拍：每个时钟沿 SRAM 写使能均为 0，初始值 0x55667788 未变化，PC 保持。
- 允许后下游未就绪 3 拍：每个时钟沿 SRAM 写使能仍为 0，初始值保持，PC 保持。
- 下游就绪后：SRAM 正好写入 1 次，CPU 恢复执行，发出 1 次读访问并读回 0x1234ABCD。mcause=0，完成标记=0x60。复跑通过。

## 适用范围

该适配层只覆盖单笔受检查的合法字写。延时和下游就绪由测试台控制。未验证公开 CPU 默认握手、多笔在途请求、RIB 仲裁或拒绝到 CPU 异常的映射。上一轮独立模块的拒绝断言单独保留。该结果用于验证接线与测试方案，不能作为流片芯片的行为结论。当前镜像仅用于仿真。

复现入口 run.ps1。run.log 保存断言结果，cpu_wait.vcd 保存波形，compile_args.json 保存编译参数。
