# CY63300 V143 OLED 接头首帧采集结果

## 实测条件

仅使用已通过 V142 的 OLED，仍由 STM32 一侧供电。用户移除了 CY63300 原接 OLED，两板上电后接通 CY63300 H2-2/GND、H2-3/SCL 到 PB8、H2-4/SDA 到 PB9，H2-1/VDD_IO 留空。STM32 通过 ST-Link 运行 SRAM 采样器，PB8/PB9 浮空输入，GPIOB_CRH 读回 0x44444444。接线后启动采样前连续三次读到两线高。

CY63300 使用 V140 的 0x3C 配置，冷启动检查通过，PAD1=AF6、GPIOB DRIVE=0xC、MODULE_CTRL=0xF、FIFO_STA=5、I2C_STA=0。只写一次 TX FIFO 0x00，未追加 STOP。目标写入 18 次，其中 17 次初始化和 1 次 FIFO。

## 同步观测

| 项目 | 实测 |
|---|---|
| STM32 采样窗口 | 按 72 MHz DWT 周期换算 40.855 秒 |
| CY63300 FIFO 写入 | 采样启动后 16.122–16.159 秒 |
| CY63300 写后轮询 | 60 组均为 FIFO_STA=0x104、I2C_STA=1、RAW=0，末组距写入 22.715 秒 |
| OLED 端数字边沿 | 0 个，记录缓冲未满，未观察到 START 或 SCL 脉冲 |
| 停止后 STM32 端 | CRH=0x44444444，实读 IDR=0x0000FF93，PB8/PB9 仍为高 |

STM32 于 0x200030E2 暂停采样循环，读回包含本阶段唯一 magic 的邮箱。CY 的 FIFO 入队与卡点已复现，但该次测试在 OLED 接头侧没有观察到地址阶段。第九拍不存在可判读的采样，无法判断 ACK。

## 下一次判别

优先做同线束正对照。在新的干净 GPIO 模式下让 CY63300 分别用开漏拉低和释放 H2-3、H2-4，再用同一 STM32 程序采集。两条线都能捕获时，可把排查重点推进到硬件 I²C 启动和 PAD 输出路径。如果某一条抓不到，先定位该线的接点和网络。此轮未做该正对照，零边沿结果仍依赖线束连通和采样器输入阈值。

STM32 保持高阻，采样 CPU 已暂停，未恢复原 OLED 驱动。CY63300 最后采样时传输仍卡住。STM32 继续与 CY63300 共用 SCL/SDA 期间保持供电与高阻，恢复原 OLED 驱动前应先断开两根板间信号线。
