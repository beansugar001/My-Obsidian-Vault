- 已通过 ST-Link 实测 STM32 CRH=0x44444444，邮箱 READY=1，PB8/PB9 均读高。等待用户接入三根信号/地线。CY63300 运行入口复用 V140 的已固定哈希 Tcl，使用 V143 独立 marker。

- 解码离线检查已通过，包括 0x3C ACK、0x3D NACK、总线持续空闲和仅 START 的不完整帧。
- STM32 已保留高阻采样程序，现等待共地、SCL、SDA 三线接好。CY63300 尚未访问。接线完成后按 ST-Link arm、CY63300 单发、ST-Link read 的顺序执行。
