# GPIO 独立观测镜像实物烧录

用户确认 H2-3 和 H2-4 已与 OLED、STM32 和外部驱动断开。烧录前读取完整 64 KiB 启动扇区，与双地址计数备份逐字节一致。仅擦写首个 512 字节启动页，写入 496 字节 GPIO 观测镜像。写后独立读回完整 64 KiB，SHA256 为 `1CF87E6B000EFC9E92F2635FA031FA302645A5F771F21108A583A98A5695ED63`，与预期逐字节一致。

## 待采样

第一阶段需要断开 DAPLink 和目标板之间的接头，板子仅用 Type-C 冷启动。万用表黑表笔接 H2-2/GND，红表笔分别测 H2-3/DONE 和 H2-4/REPEAT。预期正常时 H2-3 约为 VDD_IO，H2-4 约为 0 V。

记录基准电平后，再确认 DAPLink 接回状态，通过 JTAG 只读比较两处计数，同时观测 H2-4。若计数增长且 H2-4 拉高，可确认固件走到了完成后的计数写回路径。如果计数增长且 H2-4 保持低，则尚不能确定是未经过标记路径的写回还是调试读回。现阶段只有烧录与校验结果，实物 GPIO 电平尚待记录。
