# CY63300 V145 同线束反向开漏实测

## 实验与结果

保持 V144 线束，H2-3/SCL 接 STM32 PB8，H2-4/SDA 接 PB9，共地，OLED 仍由 STM32 侧供电。CY63300 在前后检查中均为 GPIOB_DIR=0、AFR1=0、PUPD=0x300、PERI_CLKEN=1、PERI_RST=0。整个实验 CY63300 目标 MMIO 写入为零。STM32 通过 SRAM 程序一次只开漏拉低一条线，按 DWT 自动释放，最后 CRH=0x44444444，PB8/PB9 均为高阻。

| STM32 操作 | STM32 GPIOB_IDR 掩码，两次 | CY63300 同窗口采样 | CY63300 IDR / 掩码 |
|---|---|---:|---|
| 两线空闲 | 0x300 / 0x300 | 22 | 0x2C / 0xC |
| 只拉低 SCL，4 秒 | 0x200 / 0x200 | 17 | 0x2C / 0xC |
| 释放 | 0x300 / 0x300 | 17 | 0x2C / 0xC |
| 只拉低 SDA，4 秒 | 0x100 / 0x100 | 17 | 0x2C / 0xC |
| 最终释放 | 0x300 / 0x300 | 17 | 0x2C / 0xC |

按 STM32 的 ARM 主机时间和 DWT 记录对齐，仅选每段中心稳定采样，避开边界至少 200 ms。CY63300 共读 107 次。STM32 低电平由 GPIO 实际 IDR 证实，CY63300 两个 GPIO 输入位始终读高。结合 V144 正向 GPIO 请求在 STM32 端没有边沿，当前双向实验证据都未建立跨板电气通路。尚不能定位是外部接点/线束、H2 至载板路径或 CY63300 GPIO 输入/输出路径。

第一次运行的 CY Tcl 生成时漏掉 init，OpenOCD 在预检失败，STM32 未动作，目标写入为 0。补回初始化与 TAP、探针、CPU 检查后离线通过，保留首轮日志并使用独立文件执行第二轮。

## 下一项判别

1. 断开两板电源及两个调试器 USB，保留当前线束。电阻档短接表笔记录底数。
2. 测 CY63300 H2-3 金属针脚至 STM32 PB8 金属针脚，再测 H2-4 至 PB9。均应接近表笔短接阻值。需要时再核对两板 GND。
3. 线束通后再测蓝板 H2-3 至 H4-8，H2-4 至 H4-9；随后沿对应的载板接点测到 PAD8/PAD9 连接端。测试时按照实际插接的对应脚核对，避免推测编号。
4. 若跨板与板内全通，再在 STM32 拉低时直接测 H2 与载板端电平，区分实际低电平和 CY 的 GPIO 读值。

STM32 本轮自动释放后暂停，维持高阻。板间 SCL/SDA 相连时不要单独重启 STM32 的原 OLED 驱动。
