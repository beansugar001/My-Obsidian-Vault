# V146 H2-3/SCL 电压同步实测

- [x] 确认 CY63300 两脚处于输入态，STM32 安全接管 SCL
- [x] 留 14 秒空闲，开漏拉低 SCL 15 秒，再恢复高阻
- [x] 同时读 CY63300 GPIOB_IDR，等待并归档用户万用表读数

测试点黑表笔 H2-2/GND，红表笔 H2-3/SCL。板间 GND/SCL/SDA 已接。CY63300 若处于冷启动，只允许开 GPIO 时钟并设置 PB2/PB3 内部上拉，确认 DIR=AFR1=0，硬件 I²C 始终关闭。STM32 SRAM 临时程序仅开漏拉低 PB8，PB9 一直高阻。计时结束自动释放。用户读数到手后再对照实际电压与 GPIO 输入。

- 用户表读数：H2-3 空闲 3.27 V，拉低约 0.x V。CY 同一窗口 68 次仍读高。
