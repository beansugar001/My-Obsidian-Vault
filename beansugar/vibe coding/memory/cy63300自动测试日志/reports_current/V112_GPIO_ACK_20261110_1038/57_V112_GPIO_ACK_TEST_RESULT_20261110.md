# V112 GPIO 地址 ACK 测试结果（2026-11-10）

## 结论

硬件 I²C 控制器保持关闭时，CY63300 GPIO 能在 Pad8/Pad9 上按预期拉低和释放信号；但新上电后 GPIO 默认输入采样两线都低，设置内部上拉 `PUPD=0x300` 后两线读高。随后只发了一帧 `0x3C` 写地址字节 `0x78`，第九拍 SDA 读高，结果为 **NACK**。STOP 后两线回到高电平。OLED 尚未收到任何初始化命令或显示数据。

## 证据解读

1. A2 证明内部上拉设置能令 GPIOB2/3 的输入采样转高。A1 的低读数更像是这些线在默认无上拉时浮空或没有有效外部上拉；它不是外部连接器电压的直接测量。
2. A4 证明软件产生的 SDA 低/高及 SCL 低/释放变化能被同一 GPIO 输入路径采到，且事务结束回到高。因为没有独立示波器探头接在 OLED 四针接口处，仍不能确认实际连接器上出现了完整、幅度合格的波形。
3. 第九拍 SDA 高表示芯片 GPIO 采样点没有看到从机拉低 ACK。结合 2026-11-07 的 V90 结果（`0x3C`、`0x3D` 均 NACK），当前最有区分度的下一步是观察 OLED 插座端的 SDA/SCL 波形和第九拍，而不是继续更改 I²C 控制器寄存器。
4. NACK 本身不能单独证明 OLED 损坏，也不能排除 Pad 到连接器的板级映射、供电/地参考、接口电平或模块地址/模式问题。用户此前确认接线与 OLED 可用，是有价值的背景，但目前缺少连接器端独立电气观测。
