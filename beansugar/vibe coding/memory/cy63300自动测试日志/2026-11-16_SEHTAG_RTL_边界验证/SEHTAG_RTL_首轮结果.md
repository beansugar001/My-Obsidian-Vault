# SEHTAG RTL 首轮内存边界检查

## 结果

Icarus Verilog 12.0 对 Repo_Fanglongrui 提交 189fff578a44b61a328af08e32e60ac890b19a91 进行了离线模块仿真。仓库源文件未修改。未连接实物。

- 原始 bnbcache_tb 两项失败：下界读回为 0，低于预期下界的地址未被它判为越界。原台未连接 bnb_lookup_wt，该 RTL 按该信号分拍写入下界与上界。vvp 返回 0，但日志中的 FAIL 仍计作失败。
- 独立测试副本补齐端口并分两拍装载上下界。日志含 11 项 PASS、0 项 FAIL，其中区间内、低于下界和高于上界三项均符合预期。本轮只覆盖这些样本。
- 独立 ex 台直接输入检查通过或拒绝结果。合法读和写通过，拒绝读关闭访存及寄存器写回，拒绝写关闭总线请求与写使能，并保持模拟存储单元原样。拒绝时 RTL 请求向 mcause 写 0x5 并跳向配置的异常入口。这是该提交的 RTL 取值。初次台架把标签运算结果绑零造成合法读断言失败，修正该测试输入后 4 项通过。
- 两项模块仿真独立运行。下一轮核对 CPU 顶层的检查结果与总线请求时序，在合成内存模型中确认端到端提交和异常。生命周期与样片验收未执行。

## 证据

bnbcache_run.log 为原始测试台日志。bnbcache_compat_tb.run.log 和 ex_policy_tb.run.log 为复核结果。目录中包含测试台、编译参数和 VCD。
