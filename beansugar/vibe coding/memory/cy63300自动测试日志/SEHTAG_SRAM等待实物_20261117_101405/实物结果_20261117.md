# CY63300 SRAM 等待对照实物结果

实物样品为 CJPCBT021-G。只擦写首个 512 字节启动页，写入 172 字节对照镜像。完整 64 KiB 独立读回与预期逐字节一致，SHA256 为 `B7B81AB8C5D55E18ABDB8139F5BF8800E55DC61DBF36FFFC6E7D038620496DAD`。冷启动后再次读取 172 字节，仍与镜像一致。对照程序没有 CSR 指令。

| 实物记录 | 值 |
| --- | --- |
| 首次从 SRAM 读取的值 | `0x00000000` |
| 比较值 | `0x53454152` |
| 退出时记录的读值 | `0x00000000` |
| 退出路径 | `2`，曾进入等待后又走进退出代码 |
| 退出时读值与比较值的异或 | `0x53454152`，非零 |
| 状态字 | 等待 `0x57410001` 和异常退出 `0x5741FA11` 均出现 |
| 上位机写入测试字 | 0 次 |

逐字采样先后观察到异常退出和等待。因此脚本停止，未写错误值或正确值。另开只读会话，整块读取邮箱八次。六次为异常退出，两次为等待。其余七个字一致。无重试写入、复位或 CSR 操作。

观察证明普通 SRAM 对照程序也出现了无主机触发的退出记录。记录中的两值不相等，因此正常的触发值匹配无法解释这一记录。状态字波动仍需区分 CPU 重复写回、执行流异常和调试端读回异常。当前证据未定位到具体分支指令或硬件单元。

下一步先比较同一邮箱在 CPU 运行和明确 Halt 后的重复读回，保存可用的 PC/DPC 观察。若 Halt 后仍不一致，优先检查读回链路。若 Halt 后稳定，再用纯寄存器条件分支对照隔离 SRAM 读指令及其到分支的间隔。实物当前保留 SRAM 等待对照镜像。
