# CY63300 V158 片上硬件 I²C 显示 Hello

**PASS。2026-11-11，现场确认 OLED 左上角清楚显示 Hello。**

## 实验条件与实现

- CY63300 沿用 V156/V157 的 H2-3/SCL、H2-4/SDA 及 GPIOC0/C1 AF3 配置，OLED 七位地址为 0x3C。STM32 PB8/PB9 为高阻输入，独立采集总线边沿。
- 从 STM32 参考工程的 OLED.c 取得显示初始化和页光标命令，从 OLED_Font.h 取得 8×16 字模。源文件的 SHA256 和实际发送数据见 frames.json。
- 通过 JTAG/SBA 逐字节写入 CY63300 硬件 I²C TX FIFO。每字节确认 FIFO 排空与控制器状态，每帧写入 STOP 后确认回到空闲。使用 0x00 控制字节发送命令、0x40 发送显存数据，分别写入第 0、1 页第 0–39 列，最后发送 0xAF 开显示。本轮只改写这 80 字节显存，未做全屏清屏。

## 实物结果

| 帧 | 内容 | 包含地址的字节数 | ACK 数 |
|---|---|---:|---:|
| 0 | 显示参数初始化、页寻址模式 | 26 | 26 |
| 1 | 第 0 页，列 0 | 5 | 5 |
| 2 | Hello 字模上半部，40 字节 | 42 | 42 |
| 3 | 第 1 页，列 0 | 5 | 5 |
| 4 | Hello 字模下半部，40 字节 | 42 | 42 |
| 5 | 0xAF 开显示 | 3 | 3 |
| 合计 | 6 次 START，6 次 STOP | 123 | 123 |

STM32 抓到 2663 个边沿，无溢出。逐帧比对全部地址、数据和应答通过，首帧前和末帧后 SCL/SDA 均为高。CY63300 日志共 129 次目标 MMIO 写入，含 117 次 FIFO 写入、6 次 MCTR 清除 STOP 设置、6 次 MCTR 请求 STOP。末帧结束 FIFO_STA=0x05、I2C_STA=0x00、RAW_INTR_STA=0x00。

用户反馈：“清楚显示 Hello”。

此结果验证了以 JTAG/SBA 给片上硬件 I²C 控制器送数据的 OLED 显示链路。CY63300 独立运行固件时的上电初始化与显示留待后续验证。两块芯片的 Flash 均未修改。
