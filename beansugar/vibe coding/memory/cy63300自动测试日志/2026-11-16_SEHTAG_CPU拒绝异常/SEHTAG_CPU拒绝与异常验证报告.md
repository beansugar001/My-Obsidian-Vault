# SEHTAG CPU 拒绝与异常入口对照验证

基线 Repo_Fanglongrui 189fff578a44b61a328af08e32e60ac890b19a91。Icarus Verilog 12.0，xPack GCC 8.3.0。使用此前独立仿真副本，新增拒绝结果至 CSR 和 PC 的接线。未改原仓库，未连接实物。

同一固件自然启动，开启检查、合法分配对象并向对象内发出一次写请求。两次独立运行仅改变测试台的抽象判定注入，目标地址和数据相同。

| 实验 | 总线写入 | 总线读取 | SRAM 末值 | CPU 结果 |
|---|---:|---:|---|---|
| 允许 | 1 | 1 | 0x1234ABCD | mcause=0，正常结束标记 0x60 |
| 注入拒绝 | 0 | 0 | 0x55667788 | 一次拒绝，mcause=0x5，PC 到达 mtvec 所设入口 0x600，处理程序读回原因码并写出 0x61 |

两项断言均通过。0x5 沿用公开 RTL 的内存违规编码。对照验证的是拒绝信号如何阻止写入并引导 CPU 进入异常处理。拒绝由测试台对合法请求注入，本轮未验证样片能否产生对应拒绝结果，未验证 mepc、mstatus、mret 或完整异常返回语义。该镜像仅用于仿真。

run.ps1 可复现。allow.log、deny.log、allow.vcd、deny.vcd 保存原始结果。
