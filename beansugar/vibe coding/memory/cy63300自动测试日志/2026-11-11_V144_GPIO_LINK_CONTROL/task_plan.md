# V144 同线束 GPIO 正对照

- [x] 派生 GPIO 脉冲脚本，复用 V141 的 SBA 写后验证与 V143 的 STM32 高阻采集
- [x] 离线验证写入预算及脉冲顺序
- [x] 等用户冷启动 CY63300 并恢复线束后执行
- [x] 对照 STM32 实测边沿并归档

冷启动确认 CLKEN/RST 各三次为 0。只开 GPIO 时钟，保持 GPIOB AF0、ODR=0，设置开漏及上拉。先 SCL 拉低一次，再 SDA 拉低两次，每次保持至少 300 ms 后释放。通过 DIR 切换，未改变的线需保持输入高电平。正常 9 次目标写，异常时最多增加一次只释放两线的写；无 I²C FIFO、复位或非易失写入。STM32 使用原 SRAM 采样器，高阻并保持供电，采集完成后保持高阻。

- 实物已完成，CY 脉冲方向读回均正确，STM32 两线边沿数均为零。
