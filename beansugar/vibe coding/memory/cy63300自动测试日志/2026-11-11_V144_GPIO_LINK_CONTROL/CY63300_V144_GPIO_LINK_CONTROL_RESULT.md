# CY63300 V144 同线束 GPIO 正对照

用户断开板间两根信号线后重新上电 CY63300，随后恢复 H2-3/SCL 至 STM32 PB8、H2-4/SDA 至 PB9 与共地。仍使用 V142 验证过的 STM32 侧 OLED，H2-1 留空。STM32 CRH=0x44444444，采样前空闲三次均 SCL/SDA 高，启动后等待 CY 实验结束。

| 检查 | 实测 |
|---|---|
| CY63300 冷启动 | CLKEN/RST 各三次读 0 |
| GPIO 模式 | GPIOB AFR1=0、ODR=0、OSOD=0xC、PUPD=0x300；PERI_CLKEN=1，硬件 I²C 时钟关闭 |
| SCL GPIO 指令 | DIR=0x4 后归 0；低和释放检查点相距 894 ms |
| SDA GPIO 指令 | 两次 DIR=0x8 后归 0；检查点相距 899 ms、897 ms |
| STM32 OLED 侧 | 从实验开始前到实验结束后，边沿计数 0，未溢出，起止 PB8/PB9 均读高 |
| 写入次数 | 9 次，其中 GPIO 时钟、上拉、开漏配置各一次，DIR 切换六次；硬件 I²C FIFO 写入 0 |

按数字设计文档 RISC-V PADMUX 原表，PAD8/9 在 AF0 确为 GPIOB2/3。方向与开漏读回正确只说明配置被写入。STM32 这次未观察到正对照脉冲，故 V143 的零边沿仍不能区分 CY GPIO/PAD 输出路径、板上连接、跨板线束和采样输入。两个方向的实际引脚连通尚无独立证据，不能由本结果下 I²C 状态机损坏结论。

下一项建议反向拉低对照。保持 CY63300 GPIO 输入、I²C 时钟关闭，在同线束另一端用 STM32 一次只开漏拉低一条线，先确认 STM32 端真实输入低，再读取 CY63300 的 GPIOB IDR。若 CY 两线都响应，则跨板线束和 CY 输入路径成立，优先查 CY 输出链。若 CY 不响应，则逐段核对 H2 到 STM32、以及 CY 载板到 H2 的导通。此反向对照未执行。

目前两板仍处于 GPIO 高阻输入。保持 STM32 供电，板间 SCL/SDA 连接期间不要复位 STM32。
