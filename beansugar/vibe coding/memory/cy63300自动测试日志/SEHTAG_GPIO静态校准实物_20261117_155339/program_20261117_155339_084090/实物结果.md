# CY63300 GPIO 静态校准实物结果

擦写前启动扇区与 496 字节观测镜像的历史备份逐字节一致。仅擦写首个 512 字节启动页并写入 136 字节校准镜像。写后独立读回完整 64 KiB，SHA256 为 `912DDDA6816F0D705BFDEEFD3BD9812EDE6E5806D473BCD80051E61731054676`，与预期一致。

用户按指定流程断开 DAPLink、OLED、STM32，CY63300 只接 Type-C 冷启动。万用表黑表笔接 H2-2/GND，测得 H2-3 为 **0 V**，H2-4 为 **3.3 V**，符合校准设计。H2-3 由 GPIOC0 开漏拉低，H2-4 为 GPIOC1 释放并使用内部上拉。实物电压由用户独立记录，未以 JTAG 的 ODR 或 IDR 代替。

已验证当前接线和静态高低电平可用于独立观测。该校准不运行计数固件，因此不判断上一版为何两脚均为高，不判断计数是否重复写回。

下一版观测标记沿用已校准的开漏配置，H2-3 和 H2-4 上电均释放为高，分别在完成和检测到完成后再次进入写回例程时锁存为低。先记录断开 DAPLink 的基准，再加读窗口。板上当前为静态校准镜像。
