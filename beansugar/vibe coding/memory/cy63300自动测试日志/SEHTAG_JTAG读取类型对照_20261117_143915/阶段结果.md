# CY63300 读取类型与异常计数的实物对照

同一双地址镜像，同一 JTAG 会话，CPU 保持 running，OpenOCD 后台轮询关闭。四种窗口各执行四次，交错排列。窗口为 1400–1401 ms，读组每窗执行 20 条命令，每条分槽 70 ms，各组均无时间槽超限。静默窗内无目标读取。所有窗口均在前后读取原计数和副本。

| 窗口内访问 | 原计数增量 | 副本增量 | 原计数平均值 |
| --- | --- | --- | --- |
| 静默 | 13、12、14、14 | 12、13、13、15 | 13.25 |
| 轮换读取原计数和副本 | 132、128、137、147 | 134、128、136、148 | 136 |
| 轮换读取固定 SRAM 字 `0x2000F004`、`0x2000F104` | 121、133、145、141 | 121、135、146、140 | 135 |
| 只读 DMI `DMSTATUS` | 33、31、30、29 | 33、32、30、27 | 30.75 |

固定 SRAM 字读取均为 8。对照读计数字与固定 SRAM 字的增量范围重叠，原计数字地址在窗口内被读取并非大幅增长的必要条件。只读 DMI 状态也高于静默基线，增量小于两组 SRAM 读取。本轮没有目标写入、暂停、复位或烧录。

各读组控制的是命令数量。每条 `mdw` 的底层 DMI/JTAG 事务数可能多于一次 `dmi_read`，所以还不能归因于 SRAM 总线访问本身。下一步按实际底层事务数对齐，用等量纯 DMI 访问对照显式 SBA 读事务，并记录每个窗口的结束和底层事务数。另保留同样的边界读取，避免静默窗受读数方法差异影响。
