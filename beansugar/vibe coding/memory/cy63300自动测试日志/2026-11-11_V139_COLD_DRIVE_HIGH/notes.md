# V139 核对记录

- V130 冷启动实测 PERI_CLKEN/PERI_RST 三读均 0。GPIO 开时钟后，在 DIR=AF=0 的输入态加内部上拉，PB2/PB3 从低变为高。这个观察只覆盖芯片数字输入。
- V134 同一会话的 DIR 对照支持每笔写前读不同安全地址。额外读也改变了时序，精确的流片握手根因仍未知。
- V135 确实把 SDA 释放为输入后才采 ACK，0x3C 写地址的第九拍 SDA 为高。该轮是慢速 GPIO 位模拟。
- V136 直接 ADDR=0x3C 后使能成功。TX FIFO 单次写 0x00 后，60 次采样均 FIFO_STA=0x104、I2C_STA=1、RAW=0。
- V137 的 DRIVE=0xC 和 V138 的 PAD1=AF6 都是在已经卡住后写入。结果仅覆盖卡住后的更改。
- ARM IIC_Master.c 117–194 行确认 PB2/PB3 开漏、高驱动、快速、AF3 和内部上拉。200–289 行是初始化与使能，298 行起是单字节发送、FIFO/状态轮询及 STOP。参考 RTL 的 I²C 行为模型无法验证流片的状态机推进。
- 旧 V136 TX Tcl 对输出态 IDR 有精确断言，且含 NACK 和数据消耗后的 STOP 分支。V139 需要新的入口及更严的失败停止条件。GPIO 输入态检查放在 GPIO DIR/AF 切换前，写后回读前等待读事务 SBA idle。
