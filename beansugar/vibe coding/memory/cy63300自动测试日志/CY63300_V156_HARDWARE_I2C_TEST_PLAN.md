# CY63300 V156 片上硬件 I²C 主机测试方案

## 当前接线和证据

保留 H2-3/SCL、H2-4/SDA 到 STM32 PB8/PB9 及 OLED 的现有接线，共地。H2 是底板上已用的 I²C 接口。此前 V150 观察到这两根线分别只在 GPIOC0/C1 跟随外部拉低，V151/V152 也用 C0/C1 的开漏输出和 OLED ACK 实测确认了这一映射。V143 曾把 GPIOB2/B3 切到 AF3 后在同一 H2 抓包，记录为 0 个边沿。直接重复那次配置的信息量有限。

按 RISC-V 复用表，GPIOC0/PAD12 的 AF3 SCL 标为输入，GPIOC1/PAD13 的 AF3 为 SDA；GPIOB2/PAD8 的 AF3 SCL 标为双向。绑定资料中 COB 11、12 是 PAD8、PAD9。底板 H2-3、H2-4 是接口脚号，绿板 COB 11、12 是焊盘号。如果已实际量到 H2 与这两个编号的焊盘直通，则与 V150 的逻辑映射存在差异，应保留两项证据。

## 本轮试验

直接在现有 H2 做一次基于实测 GPIOC0/C1 映射的硬件 AF3 实验，判断这块实物的 H2 能否输出片上硬件主机时钟。STM32 只高阻采样。先确认两线空闲高、GPIOC 模拟发送结束且两线释放、I²C 控制器干净空闲。

仅将 GPIOC0/C1 的数字复用字段设为 AF3，若其余字段为零则 GPIOC_AFR1 为 0x1B。验证寄存器读回及开漏配置，保留其他 PAD 字段。沿用 V140 的硬件控制器配置与读回检查，PERI_RST=0、DIV0/DIV1=0x3E7、7 位 Master、地址 0x3C、FIFO 与 I2C_EN。启动 STM32 边沿记录，只向 TX FIFO 写一次控制字 0x00。确认数据阶段及出队后按参考流程结束帧，保留 FIFO/STA/RAW 和原始波形。

| 结果 | 结论 |
|---|---|
| 抓到 START、0x78、ACK、0x00、ACK、STOP，并确认 FIFO 出队 | 当前 H2 硬件主机通信通过 |
| 有 SCL 脉冲但无 ACK | 硬件 SCL 输出成立，进一步核对地址及 SDA |
| 仍无 SCL，FIFO 持续卡住 | 当前 H2/AF3 配置下未验证到硬件主机时钟，下一步核对 COB 11/12 与 H2 以及其它可接触点的实际绑定，用 GPIOB2/B3 输入/输出对照定位 PAD8/9，再换接已确认的硬件主机候选点 |

依据为 V143、V150–V155 实测和 RISC-V PADMUX 表。当前为离线修订计划。
