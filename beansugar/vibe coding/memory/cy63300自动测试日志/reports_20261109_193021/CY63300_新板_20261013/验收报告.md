## 2. 首要结论

目前可以确认接口逻辑网络；不能确认这块实物已具备安全上电条件。U1 的 PCB 对应关系、真实封装、核心 VDD 角色及电压规范尚未落实。

1. AMS1117-3.3 只明确提供独立的稳压输出 `$1N3`，通过 R1（1 Ω）串联到 `VDD_IO`。不能把 `$1N3`、`VDD_IO` 和 `VDD` 当成同一个网络。
2. `VDD` 仅明确连到 U1 符号 18 脚、C8（2.2 µF）1 脚、PCB 单针 `VDD.1` 和独立 VDD 焊盘。未见第二个核心稳压器、直接到 5 V/3.3 V 的供电通路或专用核心供电接口对。
3. U1 是通用 QFN32 符号，Name 为空，器件库没有 CY63300 具体型号属性。本报告的 U1 数字脚号仅是工程符号编号，不能替代芯片封装引脚表。
4. PCB 有 32 个有效 COMPONENT、77 个归属于这些器件的 PAD_NET。通过 Unique ID 与原理图匹配，针脚网络一致；U1 是唯一缺失正式 PCB 实例的原理图器件。
5. PCB 另有 33 个独立 PAD，属于 group1，构成四边各 8 个外围焊盘加中心焊盘。这为板上直接安装芯片提供了布局证据，不能据此认定实物已经焊芯片，也不能认定采用独立载板。

## 6. PADMUX 与 PAD0 的电气作用

PADMUX：1脚为VDD_IO、3脚为GND、2脚为匿名网络`$1N145`。2脚通过R10的1脚→2脚（1 kΩ）到`PADMUX`网络和U1符号14脚。因此1–2位置可经电阻施加高电平，2–3位置可经电阻施加低电平。未见这一节点的额外外部默认上下拉；无跳帽时外部电平约束未落实。高/低具体对应什么启动或复用模式，工程不能说明。

PAD0：1脚TDI，2脚PAD0，3脚NET6。1–2位置使PAD0接到JTAG TDI；2–3位置使PAD0接到H11.1；R11从VDD_IO对PAD0提供10 kΩ上拉。NET6不是地。两种跨接均不能据此确认芯片内部功能；若外部H11驱动与DAP同时通过错误跨接相连，可发生驱动冲突。当前实物跳帽位置未知，本轮不改变。
