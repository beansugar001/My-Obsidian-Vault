# CY63300 双地址固件的 CPU、DM 和 RIB 联合仿真

使用 TinyRISC-V 原版 CPU 核、jtag_dm、RIB 及握手模块，执行上板使用过的 372 字节双地址计数镜像。固件 SHA256 为 `7E40DA0A3E73E5505784D24F94CAB52A7E46F028CA7646F137371D2346D70441`。测试从 DTM 到 DM 的请求接口注入 DMI 操作。存储器使用简化组合读模型，SRAM 接 RIB 的 s2。没有模拟 DAPLink、真实 JTAG 物理扫描或实际流片的 AHB/APB 和存储时序。

无调试运行一次。读 DMSTATUS 和 SBA 两组分别在固件运行过程中和完成后注入请求，各扫八个启动偏移。每个用例观察 4800 个 CPU 时钟。每个 DMSTATUS 用例发 16 个请求。每个 SBA 用例发 33 个 DMI 请求，用于配置并执行 16 次只读访问。两种方式的暂停次数不可视为等量事务的性能比较。

| 条件 | 用例数 | 写出完成标记的周期 | 调试占用取指周期 | 完成后计数写入 |
| --- | ---:| --- | --- | --- |
| 无调试 | 1 | 277 | 0 | 0 |
| 运行中读 DMSTATUS | 8 | 286–289 | 13–15 | 0 |
| 完成后读 DMSTATUS | 8 | 277 | 16 | 0 |
| 运行中 SBA 读 | 8 | 309–313 | 59–62 | 0 |
| 完成后 SBA 读 | 8 | 277 | 66 | 0 |

33 个用例中，第一组、第二组和第二组副本均为 8，各计数地址只收到一次实际写入。完成后没有 SRAM 写入。流水线进入终止分支后，取指 PC 可在 `0x84`、`0x88`、`0x8C` 间短暂推进和回跳。对执行级的核查未发现终止自跳转之外的有效指令。采样日志与汇总文件中都保留了检查结果。

参考实现的取指暂停现象可以复现。已测请求时序下，没有复现实物完成后计数继续增长。实际流片控制逻辑、时钟域、扫描时序和真实互联都仍可能影响结果。本轮未连接实物。

后续实物验证应减少 JTAG 作为唯一观测通道的影响。可先用已验证的空闲 GPIO 做由固件驱动的完成及二次写回标记，用独立仪器比较不连接 DAPLink 与同一镜像接受 JTAG 读取时的行为。也可用外部串口回传，但需先复核该样品 UART 可靠性。
