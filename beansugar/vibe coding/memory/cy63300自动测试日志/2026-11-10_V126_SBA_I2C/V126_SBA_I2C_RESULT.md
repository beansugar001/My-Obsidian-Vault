# V126 SBA 直接配置与单字节发送

用户授权按此前无需 SRAM 的 JTAG/SBA 写入流程测试。V126_CLOCK 一次写 PERI_CLKEN=0x21，连续读回 0x21，RST=0；V126_PAD 四次写 GPIOB ODR/OSOD/DIR/AFR1，读回通过。V126_ARM 按 ARM 次序写 8 次寄存器后，MODULE_CTRL 期望可写位为0xD，实读0xE，I2C_EN未置位；停止在FIFO前。V126_ENABLE 依据历史实测顺序设临时地址0x50、使能0x0D、最终地址0x3C，MODULE_CTRL读0x0F，FIFO空且WORK=0。V126_SINGLE 仅向 TX FIFO 写 0x00 一次，60次轮询首尾均 FIFO_STA=0x104、I2C_STA=0x1、RAW_INTR=0；最终 module=0xF addr=0x3C，seen_data=0 drained=0 nack=0，STOP写0次。NACK未置位不证明ACK。未完成OLED命令或显示。

阶段累计目标MMIO写尝试17次（1+4+8+3+1）；未写 Flash/NVR，未软件复位或resume。各会话各自检查并在初始running时halt一次；会话间状态可能变化。最后读到FIFO仍有一字、WORK=1，断开调试器后不能假设状态保持。请不要自动重复发字节或复位。
