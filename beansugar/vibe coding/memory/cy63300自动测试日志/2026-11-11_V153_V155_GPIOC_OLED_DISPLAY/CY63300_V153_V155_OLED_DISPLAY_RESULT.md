# CY63300 OLED 实物点亮 V153–V155

CY63300 通过 GPIOC0/SCL、GPIOC1/SDA 开漏模拟 I²C。OLED 地址为 7 位 0x3C。STM32 的 PB8/PB9 保持高阻并记录边沿，独立核对字节、ACK、START 和 STOP。

| 阶段 | 线上字节 | 总线与实物结果 |
|---|---|---|
| V153 反色 | 78 00 A7 | 3 个 ACK，STM32 解码一致。用户观察到屏幕仍黑 |
| V154 点亮 | 78 00 A6 8D 14 A5 AF | 7 个 ACK，STM32 捕获 167 个边沿并解码一致。用户确认整屏亮了 |
| V155 恢复显存显示 | 78 00 A4 | 3 个 ACK，STM32 解码一致。控制器回到显示 GDDRAM 的模式 |

V154 根据既有 OLED 驱动启用充电泵，并用 A5 使显示摆脱当前显存内容，AF 开启显示。此结果验证命令从 CY63300 发出、OLED 应答并实际点亮。V155 退出全屏强制点亮。下一项是设置显存地址并写字符像素。

三个阶段使用独立 marker。CY63300 仅写 GPIOC_DIR，三次分别 68、162、70 笔。每帧结束两线均释放，硬件 I²C 控制器时钟保持关闭。V154 边沿记录跨过一次 32 位 DWT 计数回绕，已在解码时展开。
