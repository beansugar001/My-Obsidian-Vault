# SEHTAG 合法分配集成仿真

源代码为 Repo_Fanglongrui main 提交 189fff578a44b61a328af08e32e60ac890b19a91。以 Icarus Verilog 12.0 运行。仓库源文件未做修改，未操作实物。

## 结果

1. 测试台沿用仓库独立安全模块测试台的指令字段，提供一个大小为 32 字节的合法分配请求。mcu_security_system 内部的指令处理器驱动 HAT，返回有效结果，地址 0x20000000，结果标签为 1，无异常。
2. 在返回地址上查询 HAT 元数据，释放位为 0，代际号为 1。
3. 测试台将返回地址映射到本轮的 RAM，写入 0x1234ABCD 并正确读回。该写读由测试台直接驱动 RAM，未走 CPU 的受保护访存路径。

## 完整 CPU 路径的缺口

本轮证明独立安全模块可完成译码、分配和结果返回。公开 CPU 顶层的 HAT 操作入口固定为零，尚缺 CPU 译码、等待结果及寄存器写回之间的集成。独立处理器接口从 rs2_data_i 取标签，实验固件中的 halloc 包装采用立即数标签形式，两者在获得同版本的说明或可复核实现前不得当成相同的 CPU 指令接口。

实物在当前阶段没有接线、下载或烧录。建议下一轮在仿真副本验证从 CPU 复位开始的指令译码、等待、写回和合法访存，并把改动明确记录为仿真适配。

复现入口 run.ps1。编译参数 compile_args.json，原始输出 run.log，波形 security_alloc_integration.vcd。
