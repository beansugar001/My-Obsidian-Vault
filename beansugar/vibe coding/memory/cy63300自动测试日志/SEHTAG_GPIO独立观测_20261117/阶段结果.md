# CY63300 GPIO 独立观测

V150–V152 的实物记录确认 H2-3 对应 GPIOC0，H2-4 对应 GPIOC1，H2-2 为 GND。V151 验证了两脚的开漏输出，本试验使用与数字设计说明一致的推挽配置。推挽输出尚未在此镜像和实物上验证，首次只接高阻仪器。

| 接点 | 输出意义 |
| --- | --- |
| H2-3 / GPIOC0 | DONE。CPU 写出 SRAM 完成标记后拉高 |
| H2-4 / GPIOC1 | REPEAT。DONE 之后再次走到计数写回例程时拉高，并保持 |
| H2-2 | 两通道探头共用的板上地 |

镜像沿用双地址计数和直接返回指令。初始化只打开 GPIO 时钟，配置 GPIOC0/1 的复用、输出模式和方向，保留寄存器其他位。无 I²C 或 SEHTAG CSR 配置。添加了初始化和观测分支，可能改变异常出现的时序。高电平可记录 CPU 再次执行写回例程。若 JTAG 发现计数增长但 REPEAT 低，还需区分 CPU 未经过标记代码、底层事务重复以及读回异常。

Icarus Verilog 与旧 Tiny-RISC-V CPU 核通过两组仿真。正常程序为 DONE=1、REPEAT=0，完成后写回次数为零。测试台把终止处自跳转改为重进写回例程后，DONE=1、REPEAT=1，实际监测到三次完成后写回。GPIO 注册和引脚电平由测试台模拟，未模拟实物 GPIO 电气特性。

镜像长度 496 字节，SHA256 为 `AA12A9CCA3A43A1B5B55556705E04D285305812D4635A8E5CBE37600B1D1E88E`。实物阶段先核对双地址镜像的启动扇区 SHA256 `AE1EFB90046506E8009A013F12C59DD205D7C0AAB7A2CF3A80569EC15D490D97`，再只擦写首个 512 字节页，独立读回验证。

## 接线及实物步骤

1. 断电，断开 H2 上的 OLED、STM32 两根信号及任何外部驱动。信号线单独接高阻示波器或万用表，H2-1 不用于本试验。若使用示波器，CH1 尖端接 H2-3，CH2 尖端接 H2-4，两支探头地夹都只接板 GND H2-2。可先用万用表分别测两根线，黑表笔接 H2-2。
2. 探针倍率与示波器通道一致，建议 ×10、DC、1 V/div。长时间观察可先用 1 s/div。两个输出都是持续电平，万用表也可判断是否拉高。以实测 VDD_IO 为高电平参考。
3. 镜像烧录并校验后，按冷启动流程让 DAPLink 与目标断开。只给 CY63300 上电，记录 DONE 和 REPEAT。之后另做一次冷启动，在同一镜像上先记录空闲，再用相同的 DAPLink 读窗口，记录 REPEAT 是否置位以及 SRAM 原字、副本是否增长。

本轮未连接或改写实物。首次运行需对启动页擦写及 H2 接线条件确认。
