# CY63300 SRAM 加载到条件分支的对照

上一轮纯寄存器指令通过实物验证。本轮离线构造三个单次测试，共用位于 `0x100` 的同一条 `BNE`。比较值固定为 `0x53454000`，预期操作数为 `0x13579000`。两条 SRAM 加载均读取 `0x2000F030`，指令编码相同。每组分别记录分支操作数与实际路径。

| 输入来源 | 分支前序列 | 正常仿真读值／路径 |
| --- | --- | --- |
| 寄存器 | 寄存器复制、跳转到共用入口、两条 NOP | `0x13579000`／跳转 |
| SRAM，短间隔 | 由 `0xF4` 加载，再执行两条 NOP | `0x13579000`／跳转 |
| SRAM，较长间隔 | 由 `0xD0` 加载，五条 NOP、跳转到共用入口、再执行两条 NOP | `0x13579000`／跳转 |

额外的仿真对照只改变短间隔组的数据总线返回值，使其与比较值相等。该组记录 `0x53454000` 且分支未跳转，其余两组不变。此结果证明邮箱能记录操作数变化与路径变化。测试台未观察到 CSR 写操作。

较长间隔组同时经过一次额外跳转，因此若它和短间隔组的结果不同，实物证据只能确认执行序列差异相关。要将异常归因到间隔长度，需要控制跳转的后续复测。当前没有用于等待触发的循环。

## 实物步骤和验收

镜像长度为 288 字节，SHA256 为 `066E3830DD6E94BFDD9B70C8CE55F50CFEB85A4E65D664064D0F6A25A46CF531`。先独立读回当前 64 KiB 启动扇区，要求与上一轮镜像备份逐字节一致，其 SHA256 为 `1C9E931829EC1F340E5CB78059DA377FF0BDB07146CD1F697D9992FB0467FC72`。一致后仅擦写首个 512 字节页，再独立校验整个扇区。

冷启动后只读采样 `0x2000F000–0x2000F033`。邮箱标识为 `0x4C425000`，完成标记为 `0x4C426000`。三组预期各记录 `0x13579000 / 0x54414000`。加载的记录值错误时，先核对 SRAM 原始图样和 CPU 加载路径。操作数记录正确但分支路径错误时，优先检查比较、分支及与加载的时序。三组均通过后，再按原计划加入等待循环。

本轮仅完成离线构建及仿真，实物未操作。
