# CY63300 SRAM 加载到单次分支的实物结果

擦写前读回的 64 KiB 启动扇区与上轮纯寄存器对照备份逐字节一致。仅擦写首个 512 字节页，将 288 字节镜像写至 `0x00000000`。写后独立读回完整启动扇区，与预期逐字节一致，SHA256 为 `3D795D003895BE849C3B11114E3E15D86C30683C8E61E88ED09A0EF05DFD053D`。冷启动后再次读回前 288 字节，与烧录镜像一致。

| 分支输入 | 实物记录的操作数 | 分支路径 | 判定 |
| --- | --- | --- | --- |
| 纯寄存器 | `0x13579000` | 跳转 `0x54414000` | 通过 |
| SRAM 加载后两条 NOP | `0x13579000` | 跳转 `0x54414000` | 通过 |
| SRAM 加载后较长间隔 | `0x13579000` | 跳转 `0x54414000` | 通过 |

同一条 `BNE` 在地址 `0x100`，固定比较值为 `0x53454000`。两次 SRAM 加载地址为 `0x2000F030`，只读回查仍为 `0x13579000`。完成标记 `0x4C426000`。八次整块和八轮逐字读回对全部定义字段一致，均符合预期。两种读取均经同一 JTAG 调试链路。未重新触发程序或测试 CSR。

这轮确认简单的 SRAM 加载接单次条件分支能够成功。较长间隔组额外包含跳转。本次三组都通过，尚不能定位之前等待循环的提前退出。下一轮按既定计划在同一对照的基础上添加有计数上限的 SRAM 重复读取与分支，并记录实际迭代次数、最后输入和退出原因。
