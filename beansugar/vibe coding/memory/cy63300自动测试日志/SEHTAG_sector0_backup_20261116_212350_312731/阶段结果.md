# CJPCBT021-G 启动扇区备份

OpenOCD 以 100 kHz 通过 CMSIS-DAP 连接，脚本在读取前核对了探针序列号 `07000001006700343500000a4e57354aa5a5a5a597969908` 和唯一 TAP `riscv.cpu / 0x1E200A6F`。读取前 CPU 为 running。本轮没有发送 halt、CPU reset、resume、擦除、烧录或写入安全 CSR 的命令。

读取范围为 `0x00000000–0x0000FFFF`。`sector0.bin` 共 65,536 字节，与 V160 历史独立读回逐字节一致。SHA256 为 `0808DA861C1BBD7B03BB88A3ECB625798B0A0797F114788529498EEC5428CA9C`。范围覆盖启动扇区，未读取其他 Main Flash 或 NVR。

保留原始命令和日志。初次判定依赖额外的 OpenOCD 文本 `dumped 65536 bytes`，本次输出未出现该行，因而在 `result.json` 误报 FAIL。日志包含在 `dump_image` 返回后生成的完成标记。离线复核同时检查标记、链路信息、长度和与历史镜像逐字节对照，结果见 `verified_result.json`，未重新连接芯片。

数字设计说明列出了 TinyRISC-V 和玄铁 E902 两种 CPU 选择，但现有资料仍未给出这块样品与论文 SEHTAG RTL 的对应关系。公开参考 RTL 定义 `0x803` 为安全控制 CSR，复位值为 0。下一步应向项目方确认 `CJPCBT021-G`、绑定图所列 `A81000A00069` 与实际 RTL 版本的关系，并确认 `0x803` 定义、复位值以及置位后取指行为。实物探针执行和恢复均未在本轮验证。
