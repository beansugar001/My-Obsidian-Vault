## 1. 三个"物理层"概念先分清

这颗芯片在你的测试台上有一个**邦定链**，信号要穿过三层物理介质：

```
第1层 裸片(die)上的焊点(pad)      ← 数字文档里的 PAD0~PAD15/电源脚
第2层 邦定线(bond wire)           ← 29根 1.0mil 钯铜线
第3层 载体
  ├─ COB 版：直接邦定到测试板 CJPCBT021-G 的焊盘 1~29（你手里这批材料对应这版）
  └─ QFN32 版：邦到封装引线框架 → 塑封成 4×4mm 32 脚芯片（封装加工单对应这版）
```

关键事实：
- 裸片尺寸 **2052×1485 µm**（含划道），焊点 50×67µm，最小间距 27µm，铝垫厚 10500Å，硅片原厚 775µm，划道材质=钝化层、不含金属。
- 绑定线 **29 根**，1.0mil Pd-Cu（钯铜），导电胶粘片。
- **QFN32 的 22/23/24 三个脚没有绑定线（空脚 NC）**。
- 出厂测试要求（封装单备注）：**All Pin 对 GND 施加 -100µA 恒流，管脚电压应在 -1.0 ~ -0.2V**（ESD 二极管检查法）——你拿万用表二极管挡黑表笔接 GND 红表笔点各脚，读数应落在这个区间，偏差大=焊点/引脚异常。
- 同一晶圆盒里 A/B 两版混装（封装单备注2：每 5×5mm 区域 A 版 B 版混排），**邦定前必须区分**。封装单是 A 版晶圆（品号A81000A00068）的邦定表；全绑定图是 B 版（A81000A00069）。下表以封装单（A版）为基准，B版以全绑定图 PDF 图形为准（其文本层无逐脚表，焊盘序号布局一致：1~9 顶边、10~24 左边、25~29 底边）。

## 3. COB 邦定测试板（CJPCBT021-G）

全绑定图显示：裸片居中邦定，**die 焊点 1~29 直接连到板上焊盘 1~29**：
- 板焊盘 1~9 在芯片上方（右→左 1→9）
- 板焊盘 10~24 在芯片左侧（上→下）
- 板焊盘 25~29 在芯片下方

即 **COB 板上的焊盘 N = 裸片焊点 N**，对照第2节左半边表就是信号名。例如：
- COB 板焊盘 2 = PAD0（JTAG_TDI / I2C_SCL候选 / 模式配置脚）
- COB 板焊盘 3 = PAD1（I2C_SDA候选）
- COB 板焊盘 10 = PAD7，**COB 板焊盘 11/12/13 = PAD8/9/10**（I2C/SPI 候选脚，注意 COB 板上是顺序的，没有 QFN 版的交叉！）
- COB 板焊盘 19 = PADMUX，20 = 复位，25 = GND，26 = VDD，27 = VDDH

## 4. 功能复用速查（RISCV 版，完整推理见报告02第14课）

数字脚只有 16 根，一张表查"我要的功能在哪个脚、AFR1 该写几"：

| 想要的功能 | 可选脚（AFR1值） |
|---|---|
| **I2C_SCL** | PAD0(1) / PAD4(1) / PAD6(2) / PAD8(3) / PAD10(3) / PAD12(3) / PAD14(3) |
| **I2C_SDA** | PAD1(0) / PAD5(1) / PAD7(2) / PAD9(3) / PAD11(3) / PAD13(3) / PAD15(3) |
| UART0_TX | PAD0(2) / PAD4(2) / PAD6(3) / PAD8(4) / PAD10(4) / PAD12(4) / **PAD14(4←测试板用这个)** |
| UART0_RX | PAD1(1) / PAD5(2) / PAD7(3) / PAD9(4) / PAD11(4) / PAD13(4) / **PAD15(4)** |
| SPI0（四线组） | MISO=MOSI对：PAD8/9 或 PAD12/13；SCK/NSS：PAD10/11 或 PAD14/15（各AFR1=1） |
| SPI1（四线组） | 同上位置，各 AFR1=2 |
| JTAG（RISCV版） | TDI=PAD0 / TMS=PAD3 / TDO=PAD6 /（TCK专用脚） |
| SWD | SWDIO=PAD4 / SWCLK=PAD5 |
| OneWire | PAD2 |
| RTC 1Hz 输出 | PAD0(4)/PAD3(2)/PAD4(4)/PAD5(4) |
| 频率检测 F_D 输入 | PAD0(5)/PAD1(4)/PAD3(1)/PAD6(4)/PAD7(4) |
| GPIO | PAD0~5→GPIOA0~5，PAD6~11→GPIOB0~5，PAD12~15→GPIOC0~3 |

规则重申：
1. AFR1 值 n+1 = 上表括号里的功能列（0=fn0 列：GPIO 或 JTAG/SWD）。
2. **同功能多脚冲突时小编号 pad 优先**——把 SCL 配到 PAD8 前确认 PAD0/PAD4/PAD6 没被配成 SCL。
3. I2C 脚必须开漏（`Gpio_osod_type` 对应位置1）+ 上拉。

## 5. 测试底板（原.epro2 工程）信号网表

底板主要器件：USB Type-C、CH340C（USB↔UART 桥）、AMS1117-3.3（5V→VDD_IO）、12MHz 晶振（XJHCELNANF-12MHZ，20pF 负载）接 XTAL_IN/XTAL_OUT、复位按键 SW1、若干去耦/滤波阻容。

### 5.1 H4 —— 主扩展排针（2×10P，PM254-2-10-Z-8.5）

| 脚 | 信号 | 脚 | 信号 |
|---|---|---|---|
| 4 | MISO | 12 | PADMUX |
| 5 | MOSI | 13 | RST |
| 6 | CLK(SPI) | 14 | XTAL_OUT |
| 7 | CS(SPI) | 15 | XTAL_IN |
| 8 | **SCL** | 16 | VDD_IO |
| 9 | **SDA** | 17 | GND |
| 10 | UART0_RX | | |
| 11 | UART0_TX | | |

（1~3、18~20 未连网络或连接地/空。）这就是测试报告里"I2C（SDA/SCL/GND/VDD_IO）、SPI（MISO/MOSI/CLK/CS）、UART、XTAL、RST"那组接口的物理出处。

### 5.2 H7 —— JTAG/调试排针（2×10P）

已确认信号：TCK(15)、TDO(16)、TMS(13)、PAD0(10)、GND(17)；其余含 TDI/RST/VDD_IO/NET6 等（部分脚网络在工程里未显式命名，以板上丝印为准）。

### 5.3 其他
- H5（2×10P）：GND/VDD/VDD_IO 电源脚组（VDD=核电压测试点，注意与 VDD_IO 3.3V 区分）。
- H10（1×3P）、H13（1×2P）、H1/H2/H9/H11 等单排针/单点：I2C 4P 组（VDD_IO/GND/SCL/SDA）、SPI 6P 组（VDD_IO/GND/CS/CLK/MOSI/MISO）、RST 引出、启动配置脚（PADMUX/PAD0/TDI）引出。
- USB：Type-C → CH340C → UART0（这就是"串口打印/串口烧录"的通道，电脑上应枚举出 CH340 串口）。

## 6. 电源与配置脚速查

| 信号 | 要求/作用 |
|---|---|
| VDDH | 主电源 3.0~5.5V（板上经 USB 5V 直入或外部输入） |
| VDD | 核电源（LDO 输出） |
| VDD_IO | 3.3V（AMS1117-3.3 生成），IO bank 与 JTAG Vref |
| VDDHOSC/VSSHOSC | 晶振电路模拟电源/地 |
| EFUSE_VCC | EFUSE 操作电源（烧 EFUSE 时按规格供） |
| FLASH_VPP | Flash 擦写高压 0~12V（正常读=0；工厂烧录由治具给高压） |
| PAD_ANATEST | 模拟测试脚（ATE 用，用户别接东西） |
| NRST/PADRST | 低有效复位；板上 10k 上拉+按键 |
| PADMUX / PAD0 | 启动/测试模式配置（配合 TDI 形成模式选择，正常运行保持默认上下拉） |

## 7. 常见"接线自查"三分钟流程

1. 断电，万用表二极管挡：GND(黑) → 各信号脚(红)，读数都应在 0.2~1.0V 量级（对 GND 的 ESD 二极管；信号间互短则读数≈0）。
2. 通电不上程序：量 VDD_IO=3.3V、NRST≈3.3V（高）、SCL/SDA≈3.3V（上拉）或 0V（无上拉→先解决上拉）。
3. 按住复位：NRST→0V；松开回 3.3V。
4. 示波器双探头夹 SCL/SDA，跑一段最小 I2C 驱动（见报告04），看有没有 START 波形——没有 START 说明程序侧没跑起来，有 START 没 ACK 说明电气/地址问题。
