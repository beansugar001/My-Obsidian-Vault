# 01 · 芯片总览：从零认识 CY63300

> 读者假设：你会一点 C，听说过"单片机"，但对 SoC、总线、寄存器这些词还发虚。
> 读完本篇你应该能：画出这颗芯片的结构草图，说清它怎么启动、怎么被烧录、信号从引脚到 CPU 怎么走。

---

## 1. 这颗芯片到底是干嘛的？

CY63300 是杭州旗捷科技（Chipjet）设计的一颗**安全 SoC**。"安全"是它的卖点：里面塞了一整套密码学硬件（真随机数、SM2/SM3/SM4、AES、RSA、PUF 物理指纹……）。旗捷的主业是打印耗材芯片，所以它的典型应用是：**打印机墨盒/硒鼓上的那颗"防伪芯片"**——打印机要验证"这个墨盒是不是原装的"，靠的就是这种带密码硬件的小芯片做加密握手。

但抛开应用，它的内核就是一个普通的 32 位 MCU（微控制器），和我们熟知的 STM32 是同一类东西。理解它的最快路径就是拿 STM32 类比。

## 2. SoC 是什么？把芯片想成一座工厂

**SoC（System on Chip）= 把一整个计算机系统塞进一颗芯片**。把芯片想成一座工厂：

| 工厂类比 | 芯片里的东西 | CY63300 里的具体对应 |
|---|---|---|
| 厂长 | CPU（做决策、执行程序） | 32位核（M0+ / 玄铁E902 / tiny_riscv 三选一） |
| 传送带 | 总线（Bus，数据搬运通道） | AHB-Lite 主干道 + APB 支路 |
| 仓库 | 存储（放程序和数据） | Flash 256KB（断电不丢）+ SRAM 128KB（断电就丢） |
| 车间 | 外设（各干各的活） | UART/I2C/SPI/GPIO/RTC/看门狗/加密引擎… |
| 传达室 | 中断控制器（有事叫厂长） | 8 个中断源，经 SYS_IRQ_FLAG 汇总 |
| 配电房 | 时钟/复位系统 | CMU 时钟管理单元 + 分级复位树 |

**总线**值得多说一句：CPU 要读外设的寄存器，就得通过总线"喊一嗓子"：地址+读命令。AHB 是高速主干道（CPU、内存、DMA、加密引擎在上面），APB 是慢速支路（I2C、UART、GPIO 这些不赶时间的在上面），中间有一座"APB 桥"做转换。你写 `*(volatile uint32_t*)0x40002800 = x;` 时，就是这个寻址过程。

## 3. 芯片里的"房间门牌号"——存储映射

计算机世界里，一切寄存器都有地址。CY63300 的地址地图（来自设计文档 PDF 第8页 1.3.3 节）：

```
0x0000_0000 ┐
            ├ Flash 主区 256KB：0x0000_0000 ~ 0x0003_FFFF
            │   ├ 64KB 系统区（Bootloader/自检，0x0~0xFFFF）
            │   └ 192KB 用户区（0x10000~0x3FFFF，放你的程序）
0x0004_0000 ┐
            ├ NVR 区 8×512B：0x0004_0000 ~ 0x0004_0DFF
            │   NVR0 配置(用户不可见) / NVR1 修调参数 / NVR2 保护等级(OTP)
            │   NVR3 芯片UID / NVR4 密钥(RAM/BUS/FLASH key) / NVR5~7 保留
0x2000_0000 ── DataRAM 128KB：0x2000_0000 ~ 0x2001_FFFF（变量、堆、栈）
0x4000_0000 ── 外设区：所有外设寄存器（往下看表）
0xE000_0000 ── CPU 内部：SysTick 等核内寄存器
```

**外设门牌表**（这是你以后天天要查的表，两个版本 CPU 完全一致）：

| 外设 | 基地址 | 总线 | 外设 | 基地址 | 总线 |
|---|---|---|---|---|---|
| GPIO | 0x40000000 | APB0 | DMA | 0x40020000 | AHB0 |
| RTC | 0x40000800 | APB1 | ANA_TRIM | 0x40021000 | AHB2 |
| IWDG | 0x40001000 | APB2 | **SYS_CTL** | **0x40021800** | AHB3 |
| WWDG | 0x40001400 | APB3 | **FLASH_CTL** | **0x40022000** | AHB4 |
| TIM | 0x40001C00 | APB4 | CRC | 0x40022800 | AHB5 |
| **I2C** | **0x40002800** | APB5 | TRNG | 0x40023000 | AHB6 |
| SPI0 | 0x40003000 | APB6 | HASH | 0x40024000 | AHB7 |
| SPI1 | 0x40003400 | APB7 | PKE | 0x40026000 | AHB8 |
| UART | 0x40003C00 | APB8 | SKE | 0x40030000 | AHB9 |
| LPUART | 0x40004000 | APB9 | PUF | 0x40040000 | AHB10 |
| ONEWIRE | 0x40004800 | APB10 | CJ_ENC | 0x40050000 | AHB11 |
| FVT(频率/温度/电压检测) | 0x40005000 | APB11 | CJ_DEC | 0x40060000 | AHB12 |
| random_clk | 0x40005800 | APB12 | CJ_EFUSE | 0x40070000 | AHB12+ |

test.zip 里 `uart.h` 写的 `UART0_BASE=0x40003C00`、`SYSCTRL_BASE=0x40021800`，与这张表一字不差——这就是"测试代码和设计文档描述的是同一颗芯片"的铁证。

### 最重要的一个外设：SYS_CTL（系统控制器）

地址 0x40021800，全芯片的"总开关面板"：

| 偏移 | 寄存器 | 干什么的 |
|---|---|---|
| 0x00 | SYSCTL_CR0 | 时钟分频 fclk_div/pclk_div、时钟源选择、（RISCV版特有）fault_rst_en/osc_ch_req/osc_ch_ack |
| 0x08 | OSC_CR | 振荡器档位 `osc_trim_sel`：0=16M, 1=24M, 2=32M, 3=48M, 4=60M（复位值0→**上电默认16MHz**） |
| **0x0C** | **PERI_CLKEN** | **每个外设一个时钟开关位**。bit5=I2C，bit8=UART，bit6=SPI0，bit0=GPIO……复位全 0 |
| 0x10 | PERI_RST | 每个外设一个软复位位（写1复位该外设） |
| 0x14 | REMAP_CFG | remap_en：把 0x0~0xFFFF 访问重映射到 0x10000（Boot 用） |
| 0x28 | JTAG_EN | 连写两个魔数可在保护等级允许时重新打开 JTAG（0xae3847f2 → 0x3716ca98，512 个 pclk 内） |
| 0x2C | SYS_IRQ_FLAG | **仅 RISCV 版**：8 个中断标志位。bit0/1=GPIO，bit2=RTC，**bit3=I2C**，bit4~7=TRNG/HASH/PKE/SKE |

> ⚠️ **新手最常栽的坑**：任何一个外设用之前，必须先在 `PERI_CLKEN` 里把它的时钟位打开（写1）。时钟不开，寄存器读回来全是 0 或写不进去，程序"看起来对就是不工作"。复位之后所有外设时钟都是关的。

## 4. 程序怎么跑起来？（启动流程）

从按下复位到你的 main() 跑起来，发生的事（设计文档第15页 + 测试报告）：

```
上电/按复位键
  ↓ POR（上电复位）或外部 RESET 拉低 → 内部三级 DFF 同步成系统复位
  ↓ 硬件从 Flash 0x00000000 取第一条指令（PC=0）
  ↓ start.S 的 _start：
  │    1) 设置 gp（全局指针）
  │    2) 设置 sp（栈指针，指向 0x20020000）
  │    3) 把 .data 段初值从 Flash 复制到 RAM（0x20000000）
  │    4) 把 .bss 段清零
  │    5) 调 _init()：把 mtvec 指向 trap_entry（中断向量入口）
  ↓ main()：初始化 UART、中断、计时器、TRNG → 跑测试业务
```

**Boot 阶段硬件还偷偷做了一件事**（PDF 第141页 5.2 节）：上电时硬件检查 NVR1，若 word0 是魔数 `0x5A5AA5A5` 或 `0xA5A55A5A`，就把 NVR1 里的修调参数（时钟频率修正、电压基准修正等）自动搬进对应寄存器；NVR1 word5 的 `cpu_sel=0x5A` 决定选 tiny_riscv 还是玄铁 E902 核。**所以一颗芯片是什么核，是出厂烧 NVR 时定死的，软件改不了。**

烧程序有两种路子（详见报告05）：
- **JTAG + OpenOCD**：调试器接 H7 排针，OpenOCD 操纵 Flash 控制器擦写 Flash；
- **UART 串口烧录**：板上 CH340C 就是干这个的（USB 转串口接 UART0，PAD14=TX/PAD15=RX）。

## 5. 芯片怎么"说话"？——引脚只有 16 个数字脚

CY63300 是小封装芯片：数字 IO 只有 **PAD0~PAD15 共 16 根**，另有电源/复位/晶振/烧录高压等专用脚（全表见报告03）。16 根脚不够这么多外设用，所以搞了**复用（MUX）**：每根脚通过 GPIO 寄存器 `Gpio_afr1_type`（每脚 3 个 bit 选功能）决定当 GPIO、UART、I2C 还是 SPI 用。

对测试至关重要的几个脚：
- **UART0**：PAD14=TX、PAD15=RX（测试代码里配功能值 4）——串口打印/烧录
- **JTAG**（RISCV版）：PAD0=TDI、PAD3=TMS、PAD6=TDO（TCK 走专用脚）——调试烧录
- **I2C**：可选位址很多（PAD0/4/6/8/10/12/14 可做 SCL；PAD1/5/7/9/11/13/15 可做 SDA），由 AFR1 决定
- **PADMUX/PAD0**：还是启动/测试模式配置脚
- **NRST**：低有效复位，板上接了复位按键 SW1
- **VDDH**：主电源 3.0~5.5V；**FLASH_VPP**：Flash 烧录高压（最高12V）；**EFUSE_VCC**：EFUSE 电源

## 6. "安全"到底安全在哪？（外设速览，细节在报告02）

这颗芯片的安全硬件，从下到上分四层：

1. **熵源层**：TRNG 真随机数发生器（符合国家随机数检测规范 GM0008-2012，上电 1ms 内出数）+ PUF（物理不可克隆函数——利用芯片制造工艺的随机偏差生成每颗芯片独一无二的 128bit"指纹"，不可复制不可预测）。
2. **算法层**：HASH（SM3/SHA1/SHA2/MD5 哈希）、SKE 对称加密（SM4/AES/DES，支持 ECB/CBC/CTR 等模式）、PKE 非对称加密（SM2/ECC/RSA，RSA 最高 4096 位）。
3. **防护层**：总线加密（BUS_KEY 对 AHB 总线数据加扰）、RAM/Flash 存储加密（RAM_KEY/FLASH_KEY）、CJ_ENC/CJ_DEC 自研流加密引擎（带 DMA 通道）、EFUSE 一次性可烧单元存密钥、NVR 分级保护（保护等级 0~4，等级4 直接关掉 SWD 调试口）。
4. **检测层**：FVT 模块实时检测电压/温度/频率异常（防电压毛刺攻击、防超频故障注入），random_clk 随机时钟门控（打乱功耗波形，抗侧信道分析——这条对你以后的侧信道测试直接相关）。

## 7. 一图流：信号从引脚到程序的全过程

以"I2C 收到一个字节"为例，把整个链条串起来：

```
外部器件 → 测试板排针H4(脚9=SDA)
  → COB邦定板焊盘 → 芯片die上的PAD焊点(如PAD9)
  → GPIO单元(开漏驱动+施密特触发) ← AFR1选择"I2C_SDA"功能
  → I2C控制器(移位寄存器+RX FIFO) ← PERI_CLKEN.bit5开时钟, I2C_EN使能
  → APB总线 ← CPU读 0x40002808(RX_FIFO)
  → 你的C代码 i2c_read() 
  （如果开了中断：I2C中断标志 → SYS_IRQ_FLAG.bit3 → trap_entry → trap_handler → 你的ISR）
```

任何一环断了，I2C 就"跑不通"。排障就是沿着这条链逐段验证——报告04就是按这个思路写的。

## 8. 名词小抄

| 词 | 意思 |
|---|---|
| AHB/APB | 高速/慢速片上总线标准（AMBA），AHB 给 CPU/DMA/加密引擎，APB 给低速外设 |
| 寄存器 | 外设里一个个 32 位"开关+状态灯"，软件通过地址读写它们操控硬件 |
| 时钟门控 | 把不用的外设时钟关掉省电；但用前忘了开就是事故 |
| NVR | Non-Volatile Region，Flash 里划出的特殊参数区（修调/密钥/UID/保护等级） |
| EFUSE | 一次性可编程熔丝，写 0 能改、写 1 永久，比 Flash 更防篡改 |
| PUF | 物理不可克隆函数，用制造偏差当"芯片指纹" |
| XIP | eXecute In Place，代码留在 Flash 原地执行（本芯片就是这种模式） |
| COB | Chip on Board，裸片直接邦定在 PCB 上（你的测试板就是） |
| QFN | 无引脚方形封装，本芯片封装版为 4×4mm 32 脚 |
| mtvec/trap_entry | RISC-V 的中断向量寄存器/入口标号（ARM 版对应 VTOR/NVIC） |
