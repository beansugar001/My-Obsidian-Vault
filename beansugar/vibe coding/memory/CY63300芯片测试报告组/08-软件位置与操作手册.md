## 5. 已知坑（给接手者）

1. `tinyriscv.cfg` 里 `adapter_khz 1000` 偏快，杜邦线+COB 板建议降到 100。
2. JTAG 扫描"all ones" = 先查 U5 六根线（尤其 TDI，位置在脚5）和 VDD_IO 供电，再怀疑芯片。
3. H10（1×3：TDI/PAD0/NET6）是启动模式跳线，**跳线帽位置不能动**。
4. 串口 115200-8-N-1；i2c_diag 菜单：d=线电平 a=慢翻转 b=位扫 c=硬件扫 r=全跑。
5. 本机 pip 装包装到 `D:\pythonpackage\pip` 且不在 sys.path——脚本里已自行处理，直接 pip 装新包后 import 不报错才正常。
6. 历史教训：JTAG 座是 U5 不是 H7（H7 的 13/15/16 只是并联测试点，无 TDI）——别再接错。
