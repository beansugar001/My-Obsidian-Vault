# CY63300 JTAG 故障与诊断固件运行状态（2026-09-29）

## 本轮目标

在 MPU 模块 nCS/XCS 已按用户描述接到 H4-11/H13-1 后，运行新的 I2C 诊断固件，观察 nCS 拉高、GPIO 模拟探测以及 CPU 侧 I2C 控制器初始化读回。

新的诊断固件已构建，但本轮没有烧录。烧录前原计划先备份 Flash 地址 0x00000000–0x00000FFF（4 KB）。

## 当前诊断固件

- 源码：D:\project\新建文件夹\test\i2c_diag\i2c_diag.c
- 镜像：D:\project\新建文件夹\test\i2c_diag\i2c_diag.bin
- 镜像长度：3772 字节

- 本固件不发送硬件 I2C 事务，只测 nCS、GPIO 探测和控制器配置读回。

## 本轮 JTAG/OpenOCD 现象

### 第一阶段：探针可启动，但 JTAG 扫描全零

使用 tinyriscv.cfg（日志显示 1000 kHz）和随后 tinyriscv_10k.cfg（10 kHz）尝试读取并备份 Flash，均出现：

    JTAG scan chain interrogation failed: all zeroes
    riscv.cpu: IR capture error; saw 0x00 not 0x01
    dtmcontrol is 0. Check JTAG connectivity/board power.
    Target not examined yet

该状态表示 OpenOCD 已进入调试器初始化流程，但没有从目标 JTAG 链读到有效响应。它不能单独证明芯片损坏或 Flash 异常。

### 第二阶段：电脑/OpenOCD 找不到 CMSIS-DAP 探针

之后用户运行相同备份命令时，出现：

    Error: unable to find CMSIS-DAP device
    Assertion failed: jtag_trst == 0, file ../src/jtag/core.c, line 343

这发生在 OpenOCD 获取 CMSIS-DAP 设备时，早于目标 JTAG 扫描和任何目标内存操作。断言是旧版 OpenOCD 在初始化失败退出时的后续错误。

用户用 FriendlyName 匹配 CMSIS、DAP、ST-Link、J-Link 查看 PnP 设备，结果没有列出明显的调试器，但这个筛选可能漏掉以通用 USB/HID 名称显示的接口；完整 USB/HID 枚举对比尚未完成。

## 已有接线资料（来自此前原理图和排障记录）

### CY63300 与 MPU 模块

| 信号 | 板上网络/接点 |
|---|---|
| SCL | H4-8 |
| SDA | H4-9 |
| UART0_RX | H4-10 |
| UART0_TX | H4-11，与 H13-1 同网 |
| VDD_IO | H4-16；用户说明 H4-16 已与 H8-1 相连 |
| GND | H4-17 |

用户称 MPU nCS/XCS 已接到 H4-11/H13-1 网络。实际模块端子当前是否接牢、模块供电与共地是否可靠，仍需实物照片或后续测试确认。MPU 的 AD0 可选择 0x68/0x69；XDA/XCL 当前诊断不使用。

### 调试器与目标板

此前成功的 JTAG 记录（见 JTAG排查经验.md）：

    DAPLink SWCLK/TCK -> U5-1 TCK
    DAPLink TDO       -> U5-2 TDO
    DAPLink SWDIO/TMS -> U5-3 TMS
    DAPLink TDI       -> U5-5 TDI
    DAPLink GND       -> U5-6 或 U5-10 GND
    DAPLink nRESET    -> U5-8 RST（可不接）
    U5-7              -> VDD_IO（只作目标电压参考，不用探针 3.3 V 并联供电）
    H8-1 与 H8-2 短接以选择 JTAG

此前曾在 10 kHz 下识别到 TAP ID 0x1e200a6f 和 RISC-V hart；所以硬件曾经建立过 JTAG 通路。这个历史成功不能证明当前 USB 探针或跳线此刻仍连接正常。

## 下一步

1. 先确认电脑能枚举 CMSIS-DAP 探针：重新插拔探针 USB，关闭其他占用调试器的软件；对比插拔前后的 USB/HID 设备列表。
2. 运行只读 JTAG 检查：

       Set-Location 'D:\project\tools\tinyriscv-master\tools\openocd'
       .\openocd.exe -f .\tinyriscv_10k.cfg -c "targets" -c "shutdown"

3. 若提示 unable to find CMSIS-DAP device，先处理电脑到探针的 USB/驱动/占用问题。
4. 若探针初始化成功但出现 all zeroes，再检查目标供电、共地、U5 JTAG 线、H8-1/2 模式跳线和接触状态。
5. 只在成功识别 TAP/hart 后备份 4 KB，并核对文件长度为 4096；之后再决定是否烧录诊断固件。
