# 07 · 接线图（今日专用）

> 数据来源：嘉立创EDA工程《原.epro2》解析（已确认部分）+ 测试技术报告。
> ⚠️ 标注：【EDA确认】= 从工程网表解析确认；【丝印核对】= 工程里没标注，接前看板上丝印。

## 1. 总览

```
 电脑USB ──> CMSIS-DAP调试器 ──> 测试板 H7(JTAG排针)
 电脑USB ──> 测试板 Type-C(供电+CH340串口)
 万用表 ──> 测试板 H4(外设排针) 上的 SCL/SDA 等脚
 （外部I2C从机以后也接 H4）
```

## 2. CMSIS-DAP ↔ H7（JTAG 调试，烧录用）★今天的重点★

按**信号名**连，不按排针序号（不同调试器脚位不同）：

| CMSIS-DAP 引脚 | 测试板 H7 | 备注 |
|---|---|---|
| VTref / VCC(ref) | VDD_IO | **必须接**，调试器的目标电压参考(3.3V) |
| TCK | TCK 【EDA确认 H7脚15】 | 时钟 |
| TMS | TMS 【EDA确认 H7脚13】 | 模式选择 |
| TDI | TDI 【丝印核对】 | 数据进 |
| TDO | TDO 【EDA确认 H7脚16】 | 数据出 |
| nRESET | RST 【丝印核对】 | 复位控制 |
| GND | GND 【EDA确认 H7脚17】 | 共地，**不能省** |

接线口诀：**四根信号(TCK/TMS/TDI/TDO) + VDD_IO + GND (+RST 可选但建议接)**。
H7 上已确认的脚号参考：10=PAD0、13=TMS、15=TCK、16=TDO、17=GND——其中 TDI 就在 TMS/TCK/TDO 附近的空位里，看丝印找。

> 注意：H7 脚 10 是 PAD0（不是 JTAG 信号），别接错。PAD0 在 RISCV 版复位功能是 jtag_tdi，但出厂配置后可能已被复用走。

## 3. USB 供电与串口（不用改线）

测试板 Type-C → 电脑 USB：
- 供电：USB 5V → 板上 AMS1117-3.3 → VDD_IO 3.3V
- 串口：CH340C ↔ 芯片 UART0（PAD14=TX / PAD15=RX）

**同一块板 USB 和 CMSIS-DAP 可以同时插**（都共地）。不建议再外接 5V 电源与 USB 同时供。

## 4. H4 外设排针（万用表测点 / 以后接从机）

【EDA确认】的脚号：

| 脚 | 信号 | 脚 | 信号 |
|---|---|---|---|
| 4 | MISO | 12 | PADMUX |
| 5 | MOSI | 13 | RST |
| 6 | CLK | 14 | XTAL_OUT |
| 7 | CS | 15 | XTAL_IN |
| 8 | **SCL** | 16 | VDD_IO |
| 9 | **SDA** | 17 | GND |
| 10 | UART0_RX | 11 | UART0_TX |

**万用表测点（对应 i2c_diag 的 [a] 慢翻转）**：
- 黑表笔 → H4.17 (GND)
- 红表笔 → H4.8 (SCL) / H4.9 (SDA)：`a` 阶段应看到 0↔3.3V 摆动（或均值≈1.65V）
- 顺带量：H4.16 (VDD_IO)=3.3V

**以后接 I2C 从机**：
```
从机VCC ── H4.16 (VDD_IO 3.3V)
从机GND ── H4.17 (GND)
从机SCL ── H4.8 (SCL) ──┬── 4.7kΩ电阻 ── VDD_IO（上拉，若板上没有）
从机SDA ── H4.9 (SDA) ──┴── 4.7kΩ电阻 ── VDD_IO（同上）
```

## 5. 上电前 60 秒自查（万用表二极管挡）

1. 断电状态：黑表笔接 GND，红表笔逐个点 H7/H4 的各信号脚，读数应在 0.2~1.0V 量级（ESD 二极管）；读数 0 = 对地短路，先别上电
2. 通电后：H4.16 VDD_IO = 3.3V ±5%；NRST 脚 ≈ 3.3V（高电平）
3. 按住板上 SW1 复位键：NRST → 0V；松开 → 回 3.3V

三条都过 → 按《06-今日操作单》第 3 步烧录。
