## 第1课 · 简介（PDF 6~8页）：这颗芯片的"身份证"

**1.3.1 主要功能列表**告诉你它是什么档次：

- CPU：低门数处理器（文档主线写 ARM Cortex-M0+，ARMv6-M 指令集，Thumb/Thumb-2，32位硬件乘法器可选单周期或32周期，WFI/WFE 低功耗，NVIC 中断控制器最多32个外部中断+4个可配优先级）。实际总线是**单条 32-bit AMBA-3 AHB-Lite** + 一个 DAP 调试口。
- 通信外设：I2C（主从、可分频、7/10bit 地址）、SPI0/SPI1（主从、CPOL/CPHA 可配）、GPIO（文档此处写4组，GPIO章节写3组×6脚——**以3组×6=18脚为准，实际封装引出16根**）、WDT、CRC-16（多项式 x^16+x^15+x^10+x^3+1，即 0x8408 反射型）、UART0、LPUART、ONEWIRE、RTC（带数字校准）。
- 安全外设：TRNG、HASH、PKE、SKE、PUF、FD/TD/PVD（频率/温度/电压检测）、TOP_protect 顶覆防护。

> 教科书式理解：M0+ 是 ARM 家族里最小的 32 位核，2 级流水，指令少、面积小、省电——适合"够用就好"的嵌入式控制。玄铁 E902 是平头哥（阿里）的 RISC-V 入门核，tiny_riscv 是杭电自研的教学级 RISC-V 核（RV32IM 三级流水）。三者性能同一档，三选一做成三个 SKU。

**1.3.3 地址映射**（PDF 7页）：完整地图已抄录在《01-芯片总览》第3节，此处只补三个细节：
- Flash 的 64KB 系统区规划注明"需要根据自检等软件大小重新规划"——即 Boot 区大小是软硬约定，不是硬边界。
- NVR1（修调区）CPU/SWD/BIST/SDEBUG 都可擦写读；NVR2（OTP 区）只有 BIST/SDEBUG 能擦写；NVR3（UID 区）CPU/SWD 只读——**权限逐区收紧，这是芯片防篡改设计的一部分**。
- Cortex 内核外设区 0xE0000000~0xEFFFFFFF 是 ARM 标准的私有外设总线区（SysTick 在这里）。

## 第2课 · 系统架构（PDF 8~17页）：复位、时钟、存储、中断

### 2.1 复位树（PDF 8~9页）——"芯片的关机重启是怎么管理的"

原文关键句：`RESET_n 是 POR 模块产生的异步上电复位；系统内部 Reset 由 RESET_n 和外部 RESET PIN 异步复位，通过三级 DFF 同步到主时钟`。

用人话说：
- **POR**（Power-On Reset）：上电瞬间电压不稳，专用电路拉住复位线，等电源稳了才放。
- **为什么三级 DFF？** 复位信号是异步来的（不跟时钟对齐），直接用会违反触发器时序（亚稳态）。打两三拍 DFF 同步是数字设计标准手法（你论文里的 CDC 处理同一道理）。
- **分级复位**：整树是 `PORn/外部复位 → sys_rst(核) → hrst_n(AHB域) → prst_n(APB域) → 各外设独立软复位`。每个外设还有独立 soft reset 位（SYSCTL.PERI_RST@0x10），软件可以单独"重启"某个外设而不动别人。

> 实操含义：外设行为诡异时，先给它一个软复位（PERI_RST 对应位写1再写0），等价于"重启路由器"。

### 2.2 时钟系统（PDF 9~12页）——"芯片的心跳"

两个源：
- **RCH**（内部高速 RC 振荡器）：16/24/32/48/60 MHz 五档，修调后精度 ±1%。选档靠 `OSC_CR.osc_trim_sel[2:0]`（0~4 对应16/24/32/48/60），**复位值 0 → 上电固定 16MHz**。
- **RCL**（内部低速 RC）：32.768 kHz，专供 RTC/IWDG/LPUART 走低功耗。

时钟树主干（从 3.2.1 框图的文字标签还原）：
```
RCH(16~60M) ──OSCswitch──> Mclk（加扰输出 Mclk_o 供 random_clk 用）
                              │ Mclk2fclk
                              ▼
                            Fclk ──Div2/../128──> Fclk_div_o
                              │                    │
                              ▼ (mux Fclk_sw)      ▼
                          HCLK(高性能总线域)    (备选时钟)
                              │
              ┌───────────────┼─────────────┐
              ▼               ▼             ▼
           CPU核(fclk)   AHB外设(hclk)  Div2/4/8 → PCLK(APB域)
                                            │
                                   Div8 → stclken(SysTick用)
```

**CMU（时钟管理单元）的两大职责**：
1. **分频**：`SYSCTL_CR0.fclk_div[4:2]`（1~128分频）、`pclk_div[1:0]`（1/2/4/8分频）。APB 时钟 = HCLK/pclk_div。
2. **门控**：每个外设一把"锁"（PERI_CLKEN 对应位），不开锁外设就是断电状态。

**RISCV 版专属流程**（PDF 26页 4.2.1，仅玄铁E902/改版需要）：改主频分两步——先改 TRIM 寄存器（修调参数），再把 `SYSCTL_CR0.osc_ch_req` 置1 发起请求，硬件把 `osc_ch_ack` 置1 表示核同意，才完成切换。（tiny_riscv 版的时钟仲裁握手，ARM 版无此机制。）

> 实操含义：**你所有波特率、分频计算，默认都用 PCLK=16MHz 起步**（除非软件改过 trim_sel）。UART 配 115200 时 16M/115200≈138.9。

### 2.3 存储系统（PDF 12~14页）

- **Flash 主区**：256KB。头部 64KB 系统区（Bootloader+API+自检），剩 192KB 用户区。支持 XIP（代码原地执行，不用搬到 RAM）。
- **NVR 区**（PDF 12~13页逐区列了权限）：8 个 512B 小区，权限矩阵（谁可以擦/写/读）：
  | 区 | 地址 | 内容 | 权限要点 |
  |---|---|---|---|
  | NVR0 | 0x40000~ | configuration | 用户完全不可访问 |
  | NVR1 | 0x40200~ | 修调参数+cpu_sel+jtag_disable等 | CPU/SWD/BIST/SDEBUG 可擦写读；boot 自动加载 |
  | NVR2 | 0x40400~ | 保护等级花样数据(OTP) | BIST/SDEBUG 可擦写；CPU/SWD 可写读 |
  | NVR3 | 0x40600~ | UID | CPU/SWD **只读** |
  | NVR4 | 0x40800~ | RAM_KEY/BUS_KEY/FLASH_KEY | CPU/SWD 可擦写，BIST 可擦写读 |
- **DataRAM** 128KB @0x20000000。

### 2.4 中断（PDF 15~17页）

- ARM 版：NVIC 架构（Cortex-M 标准）。
- RISCV 版（你现在用的）：**没有硬件 NVIC，用 SYS_IRQ_FLAG@0x4002182C 软件轮询/分发**。8 个源（bit0/1 GPIO0/1、bit2 RTC、**bit3 I2C**、bit4 TRNG、bit5 HASH、bit6 PKE、bit7 SKE）。test.zip 的 `riscv_irq.c` 就是这么写的：`trap_entry.S` 存现场 → 读 mcause 判断是外部中断 → 读 SYS_IRQ_FLAG → 按 g_irq_vector[] 表逐个调驱动注册的 ISR → 恢复现场 mret。

**AFR1 的编号规则**（结合文档复用表和测试代码 `UART0_TX_PAD14_FUNC=4` 反推验证）：
- 每脚占3bit：pad0 用 [2:0]，pad1 用 [5:3]……pad5 用 [17:15]。
- **值0 = 第0列功能（GPIO 或 JTAG 专用），值 n+1 = 复用表第 n 列**。
- 例（RISCV版）：PAD14 复用表第3列是 Uart0_tx，所以 `AFR1[14] = 4`。PAD8 第2列是 I2C_SCL，所以 `AFR1[8]=3`（这就是旧记忆里"I2C Master 用 PAD8/PAD9 AF3"的来历）。
- **"pad编号小的复用优先级高"**（PDF 146页原文）：若同一个 IP 被配到多个 pad（比如 SCL 同时配在 PAD0 和 PAD8），硬件只认编号最小的那个。**配了 PAD8 却看到信号出现在 PAD0 上，就是这条规则在作怪。**

## 第4课 · DMA（PDF 32~52页）：让数据自己走

DMA = Direct Memory Access，"传送带工人"。CPU 下单后它可以自己搬数据，搬完喊一声（中断）。

- **架构**：单 AHB 主控 + 7 通道 + 仲裁器。CY63300 外设请求**不经过 DMAMUX，直接硬连线到通道**（PDF 35页 表4-1）：

| 通道 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 外设请求 | CJ_ENC数据入 | CJ_ENC数据出 | CJ_DEC入 | CJ_DEC出 | SPI0收 | SPI0发 | SPI1收 | SPI1发 |

- **一个"单次传输"= 一读一写两次 AHB 访问**。通道配置四件套：`DMA_CPARx`（外设地址）、`DMA_CMARx`（内存地址）、`DMA_CNDTRx`（数量，0~65535）、`DMA_CCRx`（方向DIR/优先级PL/循环CIRC/递增PINC/MINC/宽度PSIZE/MSIZE/中断使能）。
- **宽度不匹配时的自动拼拆**（PDF 39~40页 表3-1）：源8bit→目标32bit 时自动高位补0重打包；源32→8 时截低位。写入时未用数据线复制数据（写0xB0 时 hwdata=0xB0B0B0B0）。
- **错误管理**：访问保留地址 → 传输错误，硬件自动把 EN 清零，必须先清 IEIFx 标志才能重新使能。
- 注意：**I2C 没有 DMA 请求线**（通道表里没有它），I2C 大流量传输只能 CPU 搬运或软件轮询 FIFO。

## 第5课 · Flash 控制器（PDF 53~61页）：程序住的地方

核心概念三条：

1. **Flash 写只能 1→0**：像在铅笔字上描黑。所以编程前目标区域必须先擦成全 0xFF（擦除只能整扇区/整片做）。
2. **没有状态寄存器**！硬件不告诉你"忙完了没"。规则是：
   - 从 Flash 里执行的代码发起编程 → CPU 自动停止取指等待完成（安全）；
   - **从 RAM 里执行的代码发起编程 → CPU 不会等，必须软件自己延时**（大坑！OpenOCD 脚本里 `after 500` 就是在等擦除）。
3. **读写擦三态锁**：`FLS_CR.rwe_sel[1:0]`：00只读 / 01编程 / 10扇区擦 / 11全片擦。每次操作前写好、回读确认。

寄存器表（基址 0x40022000，时序复位值都是16MHz下的推荐值）：

| 偏移 | 寄存器 | 复位值 | 说明 |
|---|---|---|---|
| 0x00 | FLS_CR | 0 | [1:0]rwe_sel、[4]deep_standby、[5]row_pg_en(行快速编程) |
| 0x04 | FLS_READ | 0x1 | [1:0]read_cycle：01=时钟<35M；10=35~60M；11=>60M（读等待周期） |
| 0x08 | FLS_COMMON | 0x00100150 | [31:16]t_rw编程/擦最小间隔、[15:0]t_nvs建立时间 |
| 0x0C | FLS_WRITE1 | 0x00820480 | t_prog字节编程时间等 |
| 0x10 | FLS_WRITE2 | 0x00100010 | 地址数据建立/保持 |
| 0x14 | FLS_WRITE3 | 0x00000340 | 编程后恢复时间 |
| 0x18 | FLS_ERASE1 | 0x7DFF | 扇区擦除时间 |
| 0x1C | FLS_ERASE2 | 0x0753FF | 全片擦除时间 |
| 0x20 | FLS_ERASE3 | 0x0CA00340 | 擦除恢复时间 |

**操作配方**：
- 编程：配时序 → rwe_sel=01 → 回读确认 → 对目标地址做一次字写（触发）。
- 扇区擦：rwe_sel=10（ser_en）→ 对扇区内任意地址写任意值（触发）。
- 全片擦：rwe_sel=11（mer_en）→ 对任意地址写任意值；若写的是 NVR 地址 → NVR+Chip 都擦。
- **变频时先改 read_cycle 再提频**（不然读错数据），降频时先降频再改 read_cycle。

## 第6课 · ANA_TRIM 与安全密钥体系（PDF 61~70页）

ANA_TRIM@0x40021000 存着安全体系的"钥匙串"：

- `jtag_disable`：若该寄存器=0x12345678 且 NVR2 保护等级>3 → JTAG 关闭（上电从 NVR1 word1 加载）。
- `puf_cpu_disable`=0xc8fdc8fd → CPU 不能访问 PUF。
- `ram_key_disable`=0x08ca3ba9 → RAM 密钥改用 ANA_SFR 里的 RAM_KEY（否则用 NVR4 boot 加载的）。
- 同理 `bus_key_disable`、`fls_key_disable` 有各自魔数。
- RAM_KEY/BUS_KEY/FLS_KEY 三把钥匙分别保护 RAM、AHB 总线、Flash 的存储加密（CJ 模式）。三把钥匙都是**上电复位**（每次上电重新加载，防止调试器残留）。

> 理解：这是一套"总线/内存透明加密"——数据在存储里是密文，CPU 读到才解密。攻击者即使 dump 了 Flash 也拿不到明文。

## 第7课 · CRC（PDF 70~78页）

CRC-16，权值 16'h8408（多项式 x^16+x^15+x^10+x^3+1 的反射形式，与标准 CRC-16/MODBUS 同族）。章节含架构/寄存器/软件约束/典型场景四小节，用于通信帧校验。**软件约束**（PDF 74页附近）：CRC 计算引擎有字宽/字节序要求，按 4.7.3 寄存器表的数据寄存器宽度访问，别用半字乱敲。

## 第8课 · 安全引擎四件套（PDF 75~89页）

### 8.1 TRNG（4.8，"TNG"是笔误）
- 15K 门、上电到出数 ≤1ms@50MHz、符合 GM0008-2012（国家随机数检测规范）、内置在线健康监测、可关断省电。
- 寄存器：TRNG_CR(0x00,复位0x010100F1)、MSEL(0x04)、SR(0x08,W1C)、**DR(0x0C)数据寄存器**、RESEED(0x40,W1S重新播种)、健康检测 HT_CR/HT_SR(0x60/0x70)、熵源使能 RO_SRC_EN1/2(0x80/0x84,复位全1)、TERO 系列(0xB0~0xFC)。
- 用法：开时钟(PERI_CLKEN.bit21) → 配 CR → 轮询 SR → 读 DR。

### 8.2 HASH（4.9）
- 支持 SHA1/MD5/**SM3**/SHA2，硬件字节填充，AHB-DMA 主接口自带。
- 数据流：消息长度写 PCR_LEN(0x20~0x2C) → 消息写入 MDIN(0x100~0x17C) 或经 DMA_SA/DA(0x180/0x184) → 触发 LP_CTRL(W1S) → 轮询 SR_1 → 结果读 OUT(0x30~0x6C)。
- **大小端可配**（SYSCTL.ENC_CTL.Hash_endian）——对不上结果先查字节序。

### 8.3 PKE（4.10）公钥引擎
- 支持模运算/椭圆曲线点运算/大数乘法；配软件可实现 RSA 512~4096bit（步进32，支持CRT）、ECC P-192/224/256/384/521、**SM2**。
- 微码架构：PKE_MC_PTR 指向 ROM 里的运算微码；操作数放 PKE_MEM_A(0x400~0xE10)/PKE_MEM_B(0x1000~0x1A10) 双端口 RAM。
- 自带"存储加密"：RC_EN/RC_KEY/RC_D_NONCE/RC_A_NONCE(0x60~0x6C)——操作数 RAM 本身也加密+地址加扰，防探测。
- RAN_SEED 复位值 0x628a92e1（随机化盲化用）。

### 8.4 SKE（4.11）对称引擎
- 算法 AES-128/192/256、**SM4**、DES；模式 ECB/CBC/CFB/OFB/CTR。
- 寄存器：CTRL(W1S启动)、CFG(0x04,选算法/模式/方向)、IV(0x70~0x7C)、KEY(0x80~0x9C)、DIN(0x200~0x20C)、DOUT(0x210~0x21C)。
- **安全端口加载密钥**：SKE_SP_KEY(0x10) 写任意值触发从安全端口（PUF链路）加载密钥，密钥不经过总线——CPU 自己都看不到密钥。

### 8.5 PUF（4.12）
- 110nm 全定制 **128bit APUF**（仲裁型）+ DDPUF 变体；利用制造偏差，每颗芯片激励-响应唯一，用于生成芯片唯一身份/密钥。
- 寄存器：TEST_START/TEST_NUM(默认4096次)/TH(阈值高4086低10)/APUF_DDPUF_SEL/ASTABLE/BUSY/C_3_0~C_15_12（challenge 输入）/响应寄存器组。
- 权限：默认 CPU 可访问；NVR1 word2 魔数可禁；保护等级 3 关 PUF；SWD 读 PUF 还需 boot 的 PUF_read_en 同时允许（双保险）。

### 8.6 CJ_ENC/CJ_DEC/CJ_EFUSE（4.13~4.15）
- 自研流加密/解密引擎，key+sigma 两参数可配（sigma 相当于初始向量/序列起点），各带 DMA req/ack 四通道（对应 DMA 通道1~4）。
- CR 位域：ENC_EN/IE/DIN_DMA_EN/DOUT_DMA_EN/KEY_SEL(内部寄存器or外部输入)/SIGMA_SEL/KEY_IP_EN(密钥变换)。注意位说明里"该位仅在 XX_EN=0 时写入"——运行中不能改配置。
- CJ_EFUSE@0x40070000：读/编程时序寄存器（EFUSE_READ_TIMING 复位0x0104、EFUSE_PROG_TIMING 复位0x010120），EFUSE_VCC 专用电源脚，PORb 独立复位。

## 第9课 · RTC 与两个看门狗（PDF 99~117页）

### RTC（4.16）
- 秒分时日周月年（0~99年），自动闰年，24小时制，闹钟中断，1Hz 方波输出。
- **所有寄存器只能被 POR 复位**（其他复位动不了它——所以掉电时间不会因看门狗复位丢失；但注意它依赖 RCL 和 rtc_osc32k_clken 门控）。
- **数字校准**：每 2^20（=1048576）个 RCL 周期可以 ±1 拍，精度 0.954ppm/步，可调 ±121ppm。校准拍平均分配到 32 秒里（文档给了 127/123/122/11/6/1 档位的分布图和 ppm 对照表，PDF 100~102）。校准姿势：先实测 RCL 误差 ppm → 查表填校准值。

### IWDG（4.17）独立看门狗
- RCL 供时钟（主时钟挂了它也活着），自由递减计数器，减到 0 复位芯片。
- 寄存器带**写保护**：改 PR/RLR/WINR 前要发"解锁钥匙"（KR 写 0xCCCC 启动、0xAAAA 喂狗），有 wen_req/wen_ack 握手。
- **窗口看门狗玩法**：WINR 设窗口，过早喂狗（计数器还大于窗口值）也复位——防程序跑飞后"机械性喂狗"。

### WWDG（4.18）窗口看门狗
- PCLK 供时钟，计数器 7 位（0x40~0x7F），减到 0x40 以下复位、窗口外喂狗复位、到 0x40 可触发提前唤醒中断 EWI。
- 超时公式：`T = 4096×2^WDGTB×(CNT[6:0]+1) / PCLK`。

> 实操提示：调试时把看门狗关掉或喂勤点，否则单步一停狗就咬。

## 第10课 · I2C（4.19，PDF 117~127页）——★重点★

完整精讲在《04-I2C排障指南》，这里只放文档层面的要点：
- 带独立 TX/RX FIFO 的主从一体控制器；主从互斥（I2C_MODE.MS_MODE 二选一，**复位值1=主机**）。
- SCL 分频公式：**FSCL = FPCLK / (CLK_DIV0 + CLK_DIV1 + 2)**（DIV0 管高电平拍数、DIV1 管低电平拍数，复位值 0x20/0x30 → 16MHz 下默认≈195kHz）。
- 地址寄存器 `I2C_ADDR` 主从共用（主机当目标地址、从机当自己的地址），复位值 0x133 是个 10bit 模式残留值；7bit 模式下 bit6:3 全 1111 或全 0000 属保留地址会触发 AERR 中断。
- I2CM_CTRL.STOP 语义（易错）：0=发送队列空后拉住 SCL 等续数据；1=队列空即发 STOP 结束。
- 中断体系三层：INTR_EN（使能）/INTR_STA（屏蔽后状态）/RAW_INTR_STA（原始状态）/INTR_UNMASK（屏蔽控制）/INTR_CLR（写1清）——NACK、丢仲裁、GCALL、AERR、FIFO 溢出/下溢/阈值全套都有标志。
- 文档目录里的"I2C FeedBack DELAY 说明"正文缺失（书签错误）——从机时钟拉伸行为文档没写清楚，只能看 RTL/实测。

## 第11课 · SPI / UART / Onewire（PDF 127~137页）

### SPI（4.20）
- SPI0/SPI1 寄存器集相同，与 I2C 同款 FIFO+中断架构。MS_MODE(0x40)主从选择（复位1=主机）。
- SPI_CTRL(0x44)：CPOL/CPHA、TMOD（全双工/只发/只收）、NSS_TOGGLE、**DATA_SIZE[3:0]**（4~16bit 可选，0~2保留值会回落到8bit）。
- 分频寄存器 CLK_DIV0，模式同样有 DMA_CTRL/DMA_TH（SPI 有 DMA 请求线，通道5~8）。

### UART（4.21）
- 寄存器极简五件套：TX_RX_BUF(0x00)、STAT(0x04)、CTRL(0x08)、INT_STAT(0x0C)、BAUD(0x10，20bit bauddiv)。
- **分频规则**（原文）：bauddiv<16 按 16 算；baud=17 表示收/发一位要 17 个驱动时钟周期。即 `波特率 = UART输入时钟 / bauddiv`。16MHz/115200 → bauddiv≈139。
- 状态位：bit0 TX_FULL、bit1 RX_FULL、bit2/3 发送/接收溢出（写1清）。
- **LPUART**：编程接口与 UART 完全一致，可切 RCL 做时钟（SYSCTL_CR1.clk_lpuart_sel），APB 与 LPCLK 时钟域之间硬件握手有约 5 拍延迟——配置慢点但软件无需等待。

### Onewire（4.22）
- 单线总线（DS18B20 那种），支持 1~16 条线、标准/超速（overdrive）模式、强上拉供电（pwr 位）、presence 检测。控制/状态寄存器位域文档给了完整位表（dat/rst/ovd/cyc/pwr/irq/ien）。cdr_o/cdr_n 两个 16bit 分频寄存器定时隙宽度。

## 第12课 · FVT 与 random_clk（PDF 137~141页）——为侧信道测试预留的两件宝

### FVT（4.23）频率/电压/温度检测
- 三个检测器共用一套寄存器布局：使能→阈值（h_cnt/l_cnt）→中断/报警输出→标志与清除。
- 频率检测复位阈值：高 14408 / 低 28818（对 RCL 参考计数），可用来发现时钟被人为加速/减速（抗时钟毛刺攻击）。
- 电压检测（PVD 类）分 vd/vd_git 两路，温度检测高低温阈值可配。
- **对你的意义**：做故障注入/侧信道实验时，这颗芯片自带"环境异常报警器"，测试异常复位原因时先查 FVT 的 Int_flag。

### random_clk（4.24）随机时钟门控
- LFSR 产生随机 gate 信号，把主时钟随机"挖洞"（模式00长通/01挖1/32/10挖1/16/11挖1/8），让芯片功耗波形在时间轴上随机化。
- 用法：写 rc_seed（全0会自动置1防LFSR死锁）→ rc_mode 选档 → 时钟开始随机门控；LFSR 全0时 rc_irq 报警需重播种子。
- **对你的意义**：这就是抗 DPA/CPA 的时钟抖动防御。测侧信道时（1）先确认 SYSCTL.ENC_CTL 的 Random_clk_enable 状态，（2）采集功耗时若看到周期性"空洞"，是这玩意在工作，要么关掉做基线、要么作为防御效果评估对象。

## 第13课 · Boot 与 NVR 保护（PDF 141~143页）

### 上电自动搬运（5.2）
NVR1 word0 是"总开关魔数"：只有等于 `0x5A5AA5A5` 或 `0xA5A55A5A`，boot 才把 word1~word12 自动写入对应修调寄存器。word4~word13 逐字段的含义（原文表）：

| 字段 | 值与效果 |
|---|---|
| word1 | =0x12345678 且保护等级>3 → **JTAG 永久关** |
| word2 | =0xc8fdc8fd → 禁止 CPU 访问 PUF |
| word3 | =0x08ca3ba9 → ram_key 改用 ANA_TRIM 值 |
| word4 | =0x14ad8b3a → bus_key 改用 ANA_TRIM 值 |
| word5 | **bit[31:24]=0x5A → 选 tiny_riscv 核**，否则玄铁 E902（仅 RISCV 版支持）+ 一堆模拟修调位（porh/por/delay/vref 系列trim） |
| word6~13 | osc32k/ldo/osc 各档 trim、puf_key_en、resistor_array_en、cj_mode（bus/ram/flash 加密开关）、DPGL/DPGH/DTH/DTL/DVH/DVL 温度电压阈值、osc_fine_trim、osc_iref_trim、osc_trim16、osc_en |
| word10 | 加密使能标志（魔数 0x5a5aa5a5/0xa5a55a5a 才加载 word11），附录2 指明该标志本身有加密算法保护 |

**NVR2 word0 保护等级**（花样数据，逐位对偶防位翻转）：

| word0 值（8bit花样，按文档位模式 1111_1111 等） | 等级 | 效果 |
|---|---|---|
| 0xFF（1111_1111） | 0 | 最高保护 |
| 0xEE（1110_1110） | 1 | |
| 0xCC（1100_1100） | 2 | |
| 0x88（1000_1000） | 3 | **关闭 PUF** |
| 0x00（0000_0000） | 4 | **关闭 SWD** |
| 其他 | 7 | 默认（最松） |

**主程序红线**：文档明确"主程序不要修改 NVR1 区数据"。

### CJ加密模式（5.3）
正文只有标题（内容 presumably 在附录/保密），结合 ANA_TRIM 的 cj_mode_bus/ram/flash 位：CJ 模式=总线/RAM/Flash 三层透明加密的总开关体系。

## 第15课 · 学习自测（能答上来才算过关）

1. 上电默认系统时钟是多少？怎么改到 48MHz？（→16MHz；RISCV 版：改 OSC_CR.osc_trim_sel=3 后 osc_ch_req 置1 等 ack）
2. 为什么 I2C 寄存器写了没反应？最可能漏了哪一步？（→PERI_CLKEN.bit5 时钟门控）
3. UART0 波特率 115200@16MHz，bauddiv 写多少？（→139）
4. Flash 编程为什么从 RAM 执行时要手动延时？（→无状态寄存器，CPU 不自动等待）
5. 想把 SCL 配到 PAD8，AFR1 写什么值？如果信号出现在别的脚上最先查什么？（→GPIOB.AFR1[8]=3；查更小编号 pad 是否也配了 I2C 功能——小编号优先规则）
6. 保护等级 4 意味着什么？还能怎么调试？（→SWD 关闭；试试 JTAG_EN 魔数窗口/UART 烧录/联系旗捷 SDEBUG）
7. tiny_riscv 版的中断标志从哪个寄存器读？I2C 中断是哪一位？（→SYS_IRQ_FLAG@0x4002182C，bit3）
