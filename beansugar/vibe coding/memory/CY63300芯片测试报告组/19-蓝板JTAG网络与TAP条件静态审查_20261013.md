# 蓝板JTAG网络与TAP条件静态审查

日期：2026-10-13，北京时间。本次只读文件和离线解析；没有打开调试器、运行OpenOCD、修改接线或写Flash/NVR。

## 1. 本轮回答

下一项最有价值的检查是实际CY63300 RISC-V版本的PAD控制与TAP集成条件：外部PADMUX怎样影响JTAG选择，内部TAP复位是否释放，TAP的TDO怎样经过复用和输出使能到达实际绑定PAD。

蓝板命名网络已核对，当前没有找到能在文件中证明的TDO外接下拉或共享负载冲突。此结论不能替代实物电气条件，也不能证明封胶内绑定。手册和本地tinyriscv参考RTL不能完整建立上述实际芯片内部条件链，因此目前没有唯一根因。

## 3. 手册能证明什么（设计证据C）

来源：D:/project/新建文件夹/数字设计文档.pdf，147个物理页。

- PDF物理第146页（印刷第145页）RISCV复用表：PAD0列0为jtag_tdi；PAD3列0为jtag_tms；PAD6列0为jtag_tdo，列3为UART0_TX，列5为GPIOB[0]。
- 表内仍将PAD4/PAD5列0写为Swdio/swclk，存在变体命名混用疑点；不能单靠这个名称推出实物TCK绑定。
- 同页只有6.3 IO寄存器表及8 DEBUG模式标题，没有在该处给出PADMUX与JTAG的决策逻辑。检索现有文本未找到外部PADMUX如何控制JTAG、PAD6 TDO输出使能或完整默认选择条件。
- 文档列0不是对当前芯片内部复用状态的实测证明；复用优先级、输出使能和安全逻辑需要真正的实现资料。
- NVR与JTAG_EN机制已有文档条目；实际NVR值、TAP使能状态和可用恢复通道仍未知。本轮未对它们发送任何命令。

## 4. 本地参考RTL的具体发现（参考设计证据C）

来源：D:/project/tools/tinyriscv-master/rtl。

| 源级事实 | 定位 | 能支持的判断 |
|---|---|---|
| SoC顶层把jtag_rst_n接到rst | soc/tinyriscv_soc_top.v:345 | 此参考实现没有把TAP复位独立于该系统复位输入 |
| jtag_top把该复位接到jtag_driver的rst_n | debug/jtag_top.v:69 | 复位会进入TAP驱动 |
| rst_n为低时状态机保持TEST_LOGIC_RESET | debug/jtag_driver.v:135 | 此参考实现不能在保持该复位有效时正常进入移位状态 |
| CAPTURE_IR强制装入低位01 | debug/jtag_driver.v:164 | IR捕获应含固定的1；该装载不依赖CPU执行或TDI的图样 |
| ID由固定参数组合产生 | debug/jtag_driver.v:47～49、119 | 参考代码对应1e200a6f，与历史ID一致，但匹配ID不是实物完整实现证明 |
| TDO只在SHIFT_IR/SHIFT_DR输出移位寄存器，其余状态输出0 | debug/jtag_driver.v:260～266 | 持续低可以来自没有进入有效移位状态，并不唯一说明PAD输出损坏 |

重要更正：以前按住SW1仍扫描全零的实验，不能用来宣布固件因素或复位因素已排除。参考代码已经提供一种明确的失败解释：如果实物同样把外部复位接入TAP复位，按住键将阻止正常扫描。实际CY63300是否这样集成，仍需真顶层复位连接证明。

本地检索没有找到与实际CY63300对应的PADMUX/JTAG_EN/jtag_disable/TDO OE集成RTL。D:/project下某些研究数据集含其他芯片的jtag_enable模块，它们不属于CY63300，不能拿来补齐证据。

## 5. 最有价值的下一份已有设计资料

向老师或芯片设计方获取实际这批CY63300 RISC-V版本的以下片段即可，无需全部RTL：

1. **芯片顶层或debug_wrapper**：TAP rst_n、TCK/TMS/TDI端口及JTAG enable的连接和来源。
2. **PADMUX / pad_ring / pinmux模块**：外部PADMUX、AF字段、PAD6的TDO数据选择与输出使能/OE、复位默认态、安全禁用信号怎样组合。
3. **实际绿色COB版本的绑定表**：确认外部TCK/TMS/TDI/TDO/RST/PADMUX/VDD/VDD_IO/GND分别接到了哪些裸片PAD；A/B版资料不能自动视为兼容。

决定性问题：在当前上电、复位释放、已记录模式电平下，哪些逻辑条件让TAP获得时钟并脱离复位，以及让TDO通过PAD输出？需要源级条件链，而不是仅凭H8标签说明。

## 6. 当前结论与停止条件

探针有效回环18/18为实测A证据，当前探针基本数字收发通过。蓝板命名网络暂未发现可证明的TDO附加载荷冲突；复位对照的证据边界已纠正。当前优先级是实际目标的输入/绑定、模式、TAP reset/enable和TDO输出选通条件，不能进一步唯一定位到某颗芯片损坏或NVR锁定。

如果没有上述实际芯片集成片段和对应COB绑定关系，现有静态资料不能分开“实际TAP未工作”和“TAP工作但PAD输出未选通”。此时保存证据并请求上述资料，不重复扫频或安排新增硬件测量。
