# CY63300 当前测试板调试器连接判定

日期：2026-09-27

## 结论

当前 `D:\project\新建文件夹` 工程按 **RISC-V JTAG** 配置，现有下载流程指定 **CMSIS-DAPLink**。普通原厂固件或克隆固件的 ST-Link 不应直接用于这套工程。即使把线接到板上，现有 OpenOCD 配置也不会把 ST-Link 当作这个 RISC-V TAP 的通用 JTAG 探针。

板上的下载座是照片上方黑色 2×5 插座，PCB 设计号为 **U5**，不是 H7。H7 是芯片转接板一侧的 2×10 连接器。

## U5 实际引脚

从 PCB 元件面俯视，且保持照片方向不变，U5 的方形焊盘是 1 脚，位于右上角：

```text
左                                   右
┌────────┬────────┬────────┬────────┬────────┐
│ 9 NC   │ 7 VREF │ 5 TDI  │ 3 TMS  │ 1 TCK  │  ← 方形焊盘
├────────┼────────┼────────┼────────┼────────┤
│10 GND  │ 8 RST  │ 6 GND  │ 4 NC   │ 2 TDO  │
└────────┴────────┴────────┴────────┴────────┘
```

U5 是项目自定义引脚顺序，不能把标准 ARM 10Pin 排线整排直插后直接使用。

## 正确接 CMSIS-DAPLink

| CMSIS-DAPLink | 测试板 U5 | 作用 |
|---|---:|---|
| VTref / VCC sense | 7 VDD_IO | 目标电压参考，约 3.3 V |
| GND | 6 或 10 | 共地 |
| TCK | 1 | JTAG 时钟 |
| TMS | 3 | JTAG 状态选择 |
| TDI | 5 | 写入目标 |
| TDO | 2 | 目标输出 |
| nRESET / RST | 8 | 低有效复位 |

先用 USB-C 给测试板供电，再让调试器从 U5-7 读取目标电压。不要把调试器的 5 V 电源输出接到 VDD_IO。

## 工程依据

`D:\project\tools\tinyriscv-master\tools\openocd\tinyriscv.cfg` 明确包含：

```tcl
interface cmsis-dap
transport select jtag
jtag newtap riscv cpu -irlen 5 -expected-id 0x1e200a6f
target create riscv.cpu riscv -chain-position riscv.cpu
```

`D:\project\新建文件夹\test\i2c_diag\flash.bat` 也明确要求 CMSIS-DAP debugger。

原理图工程 `D:\project\新建文件夹\原.epro2` 中，U5 网络为：1=TCK、2=TDO、3=TMS、5=TDI、6/10=GND、7=VDD_IO、8=RST。
