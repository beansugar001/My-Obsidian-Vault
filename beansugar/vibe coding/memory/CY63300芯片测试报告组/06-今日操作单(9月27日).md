## 第1步：接线（约5分钟）

1. USB 线连测试板 Type-C → 电脑（CH340 会虚拟出串口；同时给板子供电）

## 第4步：跑诊断（核心环节）

```
python serialmon.py
```
（自动找 CH340 口；按板上 RST 键重启，出现菜单 banner）

依次发字母，记录输出：
1. **`d`** —— SDA/SCL 电平。应都是"1(高)"；有"0(低!)"先解决上拉（4.7k 到 VDD_IO）
2. **`a`** —— 万用表直流电压挡点 H4 的 SCL(脚8)/SDA(脚9)：应见 0↔3.3V 摆动（均值≈1.65V）。**哪根不动=哪根线断**
3. **`b`** —— 位扫全地址：
   - 有 ACK → 电气+从机全好，问题在控制器用法 → 继续 4
   - 全 NACK → `flash.bat i2c_diag_pin1.bin` 换 PAD0/1 再扫一遍；仍全 NACK → 从机供电/邦定/接反问题
4. **`c`** —— 硬件控制器扫描：MODULE_CTRL 读回 =0x0D 吗？读不回=时钟门控问题实锤；读得回但无 ACK=寄存器序列问题
