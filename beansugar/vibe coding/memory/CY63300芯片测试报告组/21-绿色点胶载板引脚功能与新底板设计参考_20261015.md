## 3. 调试及外设接口的含义

- TDI：调试器输出到芯片的数据；TDO：芯片返回给调试器的数据。
- TMS：调试器控制TAP状态；TCK：调试器提供扫描时钟。
- UART TX/RX：芯片发送/接收数据；使用外设复用时需由软件选择相应AF。
- SPI SCK为时钟，NSS为片选；主机模式下MOSI发往从机、MISO来自从机。
- I2C SDA为数据线，SCL为时钟线。手册只有PAD8的SCL明确标(io)，其他SCL项标(i)。硬件主机设计优先选PAD8/PAD9，不能假设任何写着SCL的PAD都能输出时钟。
- PG/TH/TL/VH/VL、TRNG相关项、BIST/sdebug及ANATEST主要属于特定测量、测试或内部功能；不据缩写猜电压或接法。

## 4. 新底板可先采用的功能分配草案

此分配以RISC-V复用表及A/B同号焊点功能一致为前提，仍需转换成实际载板孔位后才能布线：

| 用途 | 逻辑PAD | 交叉参考编号 | AF |
|---|---|---|---|
| JTAG TDI/TMS/TDO | PAD0/PAD3/PAD6 | 2/5/8 | 0 |
| JTAG TCK | 需确认B版真实定义/实际载板对应点 | 待定 | 待定 |
| I2C SCL/SDA | PAD8/PAD9 | 11/12 | 3 |
| UART0 TX/RX | PAD10/PAD11 | 13/14 | 4 |
| SPI0 MISO/MOSI/SCK/NSS | PAD12/PAD13/PAD14/PAD15 | 15/16/17/18 | 1 |
| 复位 | PADRST | 20 | 专用 |
| 模式选择 | PADMUX | 19 | 专用 |

这些功能分配互不占用同一个PAD，但仍需软件启用外设并设置AF；复用到同一IP的其他低编号PAD不能保留冲突配置，手册说明低编号PAD优先。

## 5. 原理图落地前的最少确认项

1. 绿色载板的实际型号/方向和与新插座的孔位对应；不要复制旧蓝板H7编号作载板编号。
2. B版同号焊点信号表，尤其TCK，以及PADMUX高低/默认要求。
3. VDD、VDDH、VDDHOSC、EFUSE_VCC、FLASH_VPP及ANATEST的正常应用接法、允许电压和去耦值。
4. OSCIN/OSCOUT允许的晶振类型/频率/负载；旧板装12MHz不自动等于芯片要求12MHz。

在资料未补齐时，可以建立插座机械封装、网络标签和可选连接位置；不把未知电源脚或测试脚直接硬接电源，也不把未知模式脚固定为某一档。本轮没有定稿可直接投板的完整原理图。
